Description

Design engineers must routinely determine optimal product dimensions to minimize material cost or maximize performance. In this capstone problem for Week 4, you will use MATLAB's numerical optimization solver fminbnd to determine the optimal radius and height of an open-top cylindrical storage tank.

Prediction Prompt: Differentiate $A(r) = \pi r^2 + 2V/r$ analytically: $A'(r) = 2\pi r - 2V/r^2 = 0 \implies \pi r^3 = V \implies r = (V/\pi)^{1/3}$. For $V=10$, estimate $r$: $(10/3.1416)^{1/3} \approx 3.18^{1/3} \approx 1.47\text{ m}$.

Problem Tasks

Complete the following tasks in prob_4_5.m. You are designing an open-top cylindrical tank with a fixed volume of $V = 10\ \text{m}^3$. Its surface area is $A(r) = \pi r^2 + \dfrac{2V}{r}$, where $r$ is the radius.

Part A — Define the Cost Function
Set V = 10 and define the surface area as an anonymous function A = @(r) .... Use element-wise operators (.*, .^, ./) so it is compatible with fminbnd().

Part B — Numerical Optimization
Use fminbnd() to find the radius r_min that minimizes A, searching within the interval $[0.1, 5]$ metres.

Part C — Minimum Surface Area
Calculate the surface area A_min at the optimal radius r_min by evaluating A(r_min).

Part D — Corresponding Height
Given the optimal radius, calculate the tank's height h_min using $h = \dfrac{V}{\pi r^2}$.

Part E — Visualisation (Optional Extension)
Plot $A(r)$ over $r \in [0.1, 5]$ and mark $(r_{\text{min}}, A_{\text{min}})$ with a red marker. Add labels, grid, and title.

Staged Hints

Hint 1: Concept Hint (Cylinder Area Optimization)

For an open-top cylinder, total area is base area plus cylindrical wall area: $A = \pi r^2 + 2\pi r h$. Since volume is fixed at $V = \pi r^2 h$, substitute $h = V / (\pi r^2)$ into the area equation to eliminate $h$, yielding $A(r) = \pi r^2 + 2V/r$.

Hint 2: MATLAB Syntax Hint

Anonymous functions start with @(r). Always use dot operators: pi*r.^2 + (2*V)./r. Call the solver using r_min = fminbnd(A, 0.1, 5);.

Hint 3: Code Skeleton 
% Part A
V = 10;
A = @(r) pi * r.^2 + (2 * V) ./ r;

% Part B
r_min = fminbnd(A, 0.1, 5);

% Part C
A_min = A(r_min);

% Part D
h_min = V / (pi * r_min^2);

Self-Check & Expected Properties

  • r_min should equal approximately $1.471$ metres.
  • A_min should equal approximately $20.39$ $\text{m}^2$.
  • h_min should equal approximately $1.471$ metres. Notice that $h_{\text{min}} = r_{\text{min}}$! In open-top cylindrical tank design, minimum material cost always occurs when height equals radius.

Engineering Reflection

Why does an open-top tank have minimum surface area when $h = r$, whereas a closed can with top and bottom lids has minimum surface area when $h = 2r$ (height equals diameter)? (Answer: Adding the top lid doubles the base material contribution $2\pi r^2$, shifting the balance towards a taller aspect ratio.)
