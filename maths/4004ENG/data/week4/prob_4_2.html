Problem 2: Differentiation Rules Live Core

Learning Outcomes

  • Apply the Product Rule for functions multiplied together: $(uv)' = u'v + uv'$.
  • Apply the Quotient Rule for rational functions: $(u/v)' = \frac{u'v - uv'}{v^2}$.
  • Apply the Chain Rule for composite functions: $\frac{d}{dx}f(g(x)) = f'(g(x))g'(x)$.
  • Use the simplify() function to clean up complex algebraic expressions.

Description

In calculus, complex engineering expressions are differentiated by decomposing them using standard rules. While MATLAB applies these rules automatically with diff(), understanding how to structure and simplify symbolic outputs is an essential analytical skill.

Problem Tasks

Staged Hints

Hint 1: Concept Hint (Differentiation Rules)
  • Product Rule: $\frac{d}{dx}[u(x)v(x)] = u'(x)v(x) + u(x)v'(x)$.
  • Quotient Rule: $\frac{d}{dx}\left[\frac{u(x)}{v(x)}\right] = \frac{u'(x)v(x) - u(x)v'(x)}{[v(x)]^2}$.
  • Chain Rule: $\frac{d}{dx}[g(x)]^n = n[g(x)]^{n-1} g'(x)$. For $\sqrt{u}$, the derivative is $\frac{u'}{2\sqrt{u}}$.
Hint 2: MATLAB Syntax Hint

Ensure syms x is active. Write equations with standard parentheses and asterisks: (x^2 + 5)*sin(x). Call simplify(expr) to gather terms and cancel common factors.

Hint 3: Code Skeleton 
syms x

% Part A
f_prod = (x^2 + 5)*sin(x);
df_prod = diff(f_prod, x);

% Part B
g_quot = (3*x + 1)/(x^2 - 4);
dg_quot = diff(g_quot, x);

% Part C
h_chain = sqrt(x^3 + 2*x + 1);
dh_chain = diff(h_chain, x);

% Part D
dg_simplified = simplify(dg_quot);

Self-Check & Expected Properties

  • df_prod should expand to 2*x*sin(x) + (x^2 + 5)*cos(x).
  • dg_simplified combines the numerator into a single quadratic polynomial over $(x^2 - 4)^2$.
  • dh_chain will have denominator $2\sqrt{x^3 + 2x + 1}$ and numerator $3x^2 + 2$.

Engineering Reflection

When analyzing damped harmonic vibration $x(t) = e^{-\zeta \omega_n t} \cos(\omega_d t)$, why is the product rule essential for calculating the instantaneous velocity? (Answer: The decaying envelope $e^{-\zeta \omega_n t}$ and the oscillating carrier $\cos(\omega_d t)$ both vary continuously with time $t$.)
