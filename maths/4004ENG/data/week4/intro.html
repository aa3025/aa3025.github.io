Week 4: Symbolic Calculus & Optimization

Why This Matters in Engineering

Differentiation is the mathematical foundation for calculating rates of change across all engineering disciplines. In mechanical and aerospace engineering, differentiating a position function with respect to time yields velocity ($v(t) = s'(t)$), and differentiating again yields acceleration ($a(t) = v'(t) = s''(t)$). In civil and structural engineering, beam deflection curves are differentiated to determine shear forces and bending moments. Furthermore, locating critical points where $f'(x) = 0$ is the cornerstone of engineering design optimization — minimizing weight, maximizing aerodynamic lift, and optimizing fuel efficiency.

MATLAB's Symbolic Math Toolbox allows you to perform exact algebraic differentiation, apply product, quotient, and chain rules, find tangent lines, and perform numerical optimization using fminbnd.

Before You Begin: Prerequisites & Readiness Check

  • Toolbox Prerequisite: The Symbolic Math Toolbox is required. In MATLAB, run: 
    v = ver('symbolic'); if isempty(v), disp('Symbolic Toolbox NOT installed'); else, disp('Symbolic Toolbox ready!'); end
  • Mathematical Prerequisites: Familiarity with elementary derivative rules: power rule ($\frac{d}{dx}x^n = nx^{n-1}$), product rule, quotient rule, and chain rule.
  • The 6-Step Symbolic Workflow:
    1. Declare symbols: syms x t
    2. Define symbolic expression: f = x^3 - 4*x;
    3. Differentiate: df = diff(f, x);
    4. Substitute evaluation point: val_sym = subs(df, x, 2);
    5. Convert to numeric: val_num = double(val_sym);
    6. Verify physical units and interpretation.

Quick Formative Checks

Readiness Check 1: Symbolic vs Numeric Function

Question: When should you use a symbolic expression f = x^2 versus an anonymous function handle f = @(x) x.^2?

Answer: Use syms expressions for exact algebraic operations like differentiation (diff), analytical integration (int), and formula expansion. Use anonymous function handles @(x) for fast numerical solvers like fminbnd, integral, and numerical plotting.

Readiness Check 2: Converting Symbolic Results

Question: Why does MATLAB Grader often penalize an answer even if subs(df, x, 3) evaluated to the correct mathematical fraction?

Answer: subs returns a sym object (e.g. 1/3 as symbolic text). Automated graders checking numeric values require a standard MATLAB floating-point double. Always wrap numerical evaluations in double(...): val = double(subs(df, x, 3));.

Worked Examples

Example 1: Product and Chain Rule Differentiation

syms x
% Function: f(x) = (x^2 + 1) * sin(3*x)
f = (x^2 + 1) * sin(3*x);

% Differentiate with respect to x
df = diff(f, x);

% Display in simplified algebraic form
df_simple = simplify(df);

Example 2: Tangent Line Slope and Equation

syms x
f = x^3 - 2*x + 4;
x0 = 2;

% Calculate slope m = f'(x0)
df = diff(f, x);
m = double(subs(df, x, x0));       % 3*(2^2) - 2 = 10

% Calculate y0 = f(x0)
y0 = double(subs(f, x, x0));      % 2^3 - 4 + 4 = 8

% Tangent line equation: y - y0 = m*(x - x0) -> y = m*(x - x0) + y0
fprintf('Tangent line at x=%d: y = %.1f*(x - %d) + %.1f\n', x0, m, x0, y0);

Example 3: Kinematics Analysis

syms t
% Position function of a projectile (meters)
s = 50*t - 4.9*t^2;

% Velocity is first derivative of position
v = diff(s, t);                    % 50 - 9.8*t

% Acceleration is second derivative of position
a = diff(s, t, 2);                 % -9.8 (gravity)

% Find time when velocity is zero (maximum height)
t_peak = double(solve(v == 0, t)); % 50 / 9.8 = 5.102 s
max_height = double(subs(s, t, t_peak));

Example 4: 1D Numerical Optimization with fminbnd

% Note: fminbnd requires a numerical function handle with dot operators!
fun = @(x) x.^4 - 3*x.^3 + 2;

% Search for minimum on the interval [0, 3]
x_min = fminbnd(fun, 0, 3);
f_min = fun(x_min);

% To find a MAXIMUM of g(x), minimize -g(x):
fun_max = @(x) -(sin(x) + 0.5*cos(2*x));
x_max = fminbnd(fun_max, 0, pi);

Remote Lab Help: Calculus & Symbolic Errors

  • "Undefined function 'syms'": Symbolic Math Toolbox is not installed or licensed on your current machine. Switch to MATLAB Online (matlab.mathworks.com) where all toolboxes are enabled.
  • "diff(f) differentiated the wrong variable": In multi-variable expressions (e.g. containing $x$ and $t$), always specify the differentiation variable explicitly: diff(f, t).
  • "Error using fminbnd": fminbnd cannot accept a syms expression! Pass an anonymous function handle (e.g. @(x) x.^2 - 4*x) with dotted element-wise operators.
  • Grader marks correct answer wrong: Did you return a symbolic fraction instead of a numeric double? Always use double(subs(...)) for numeric grader targets.
