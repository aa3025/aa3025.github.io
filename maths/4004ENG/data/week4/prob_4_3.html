Problem 3: Gradients and Tangent Lines Live Core

Learning Outcomes

  • Calculate the analytical gradient (slope $m$) of an engineering curve at a specific point.
  • Construct the exact symbolic equation of a tangent line using point-slope form: $y = y_0 + m(x - x_0)$.
  • Determine the gradient of the perpendicular normal line ($m_{\text{normal}} = -1/m$).
  • Verify tangency and perpendicularity conditions.

Description

In structural design and highway alignment, knowing the exact gradient and tangent profile prevents abrupt curvature discontinuities. In this exercise, you will calculate curve slopes, construct tangent lines, and derive orthogonal normal lines.

Problem Tasks

Complete the following tasks in prob_4_3.m. Recall that the tangent line to $f(x)$ at $x=a$ is $y = f(a) + f'(a)(x-a)$.

Part A — Calculate the Gradient
Given $f(x) = x^3 - 4x^2 + 5$, store it as f and calculate its derivative df. Substitute $x=3$ into df and convert to a number using double() to get the gradient m_gradient.

Part B — Evaluate the Function
Substitute $x=3$ into f and convert to a number using double() to get the $y$-coordinate y_coord.

Part C — Equation of the Tangent Line
Using $y =$ y_coord + m_gradient * (x - 3), build the symbolic expression y_tangent.

Part D — Gradient of the Normal Line
The normal line's gradient is the negative reciprocal of the tangent's gradient: m_normal = -1 / m_gradient. Calculate it.

Part E — Visualisation (Optional Extension)
Plot $f(x)$ over $[1, 5]$, then overlay the tangent line y_tangent and the normal line through $(3, y_{\text{coord}})$. Add grid on and a legend.

Staged Hints

Hint 1: Concept Hint (Tangent and Normal Lines)

The derivative $f'(a)$ gives the slope $m$ of the tangent line touching the curve at $(a, f(a))$. The equation of any line passing through $(x_0, y_0)$ with slope $m$ is $y - y_0 = m(x - x_0)$. Two perpendicular lines have slopes related by $m_1 m_2 = -1 \implies m_2 = -1/m_1$.

Hint 2: MATLAB Syntax Hint

Declare syms x. Evaluate slopes and coordinates using double(subs(df, x, 3)) and double(subs(f, x, 3)). Assemble y_tangent using symbolic x.

Hint 3: Code Skeleton 
syms x

% Part A
f = x^3 - 4*x^2 + 5;
df = diff(f, x);
m_gradient = double(subs(df, x, 3));

% Part B
y_coord = double(subs(f, x, 3));

% Part C
y_tangent = y_coord + m_gradient * (x - 3);

% Part D
m_normal = -1 / m_gradient;

Self-Check & Expected Properties

  • m_gradient must equal 3.0.
  • y_coord is $3^3 - 4(3^2) + 5 = 27 - 36 + 5 = -4.0$.
  • y_tangent expands to $3x - 13$. Check: at $x=3$, $3(3) - 13 = -4$ (matches $y_0$!).
  • m_normal must be $-1/3 \approx -0.3333$.

Engineering Reflection

Why do highway and railway curves require the tangent line of an entry transition spiral to match the incoming straight section exactly? (Answer: To prevent sudden lateral acceleration impulses (jerk) that would derail high-speed trains or cause vehicles to skid.)
