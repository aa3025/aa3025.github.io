Problem 1: Introduction to Symbolic Differentiation Live Core

Learning Outcomes

  • Define symbolic variables using the syms command.
  • Compute analytical derivatives of polynomial, trigonometric, and exponential functions using diff().
  • Calculate higher-order derivatives (such as second derivatives).
  • Evaluate symbolic derivatives at specific numeric points using subs() and double().

Description

This exercise introduces the Symbolic Math Toolbox, which allows you to perform calculus analytically rather than numerically. You will learn how to define symbols, differentiate standard functions, and extract numerical results for engineering applications.

Required Grader Variables

Variable Name Expected Type Dimension Description
x, t, a, b sym $1 \times 1$ syms Symbolic variable declarations
f1, f2, f3 sym $1 \times 1$ syms Symbolic function expressions
df1, df2, df3 sym $1 \times 1$ syms First analytical derivatives with respect to $x$
d2f1 sym $1 \times 1$ sym Second analytical derivative of $f_1$ via diff(f1, x, 2)
val_x2 sym $1 \times 1$ sym Symbolic evaluation at $x=2$ via subs()
df1_numeric double $1 \times 1$ scalar Numeric evaluation converted via double(val_x2)
Prediction Prompt: For $f_1 = 3x^4 - 5x^2 + 10$, differentiate by hand: $f_1'(x) = 12x^3 - 10x$. What is $f_1'(2)$? ($12(8) - 10(2) = 96 - 20 = 76$).

Problem Tasks

Complete the following tasks in prob_4_1.m.

Part A — Define Symbolic Variables
Define x, t, a, and b as symbolic variables using a single syms command.

Part B — Standard Derivatives
Calculate the derivative with respect to $x$ of each of the following, storing the functions as f1, f2, f3 and their derivatives as df1, df2, df3:

  1. $f_1 = 3x^4 - 5x^2 + 10$
  2. $f_2 = \sin(2x) + \cos(3x)$
  3. $f_3 = e^{-0.5x}$ (use exp(-0.5*x))

Part C — Second-Order Derivative
Calculate the second derivative of f1 with respect to $x$ and store it in d2f1 (use diff(f1, x, 2)).

Part D — Substitution
Calculate the numerical value of df1 at $x = 2$: substitute using subs() into val_x2, then convert to a plain number df1_numeric using double().

Staged Hints

Hint 1: Concept Hint (Analytical Differentiation)

The derivative of $x^n$ is $nx^{n-1}$. For trigonometric terms, $\frac{d}{dx}\sin(kx) = k\cos(kx)$ and $\frac{d}{dx}\cos(kx) = -k\sin(kx)$. For exponential terms, $\frac{d}{dx}e^{kx} = k e^{kx}$.

Hint 2: MATLAB Syntax Hint

Declare multiple symbols at once: syms x t a b. Call diff(f, x) for first derivatives and diff(f, x, 2) for second derivatives. To substitute, use subs(df1, x, 2) followed by double(...).

Hint 3: Code Skeleton 
% Part A
syms x t a b

% Part B
f1 = 3*x^4 - 5*x^2 + 10;
df1 = diff(f1, x);

f2 = sin(2*x) + cos(3*x);
df2 = diff(f2, x);

f3 = exp(-0.5*x);
df3 = diff(f3, x);

% Part C
d2f1 = diff(f1, x, 2);

% Part D
val_x2 = subs(df1, x, 2);
df1_numeric = double(val_x2);

Self-Check & Expected Properties

  • df1 must be 12*x^3 - 10*x.
  • df2 must be 2*cos(2*x) - 3*sin(3*x).
  • d2f1 must be 36*x^2 - 10.
  • df1_numeric must equal 76 as an IEEE double.

Engineering Reflection

Why do aerospace guidance systems rely on analytical symbolic derivatives rather than finite-difference approximations ($\frac{f(x+h)-f(x)}{h}$) for mission-critical flight equations? (Answer: Symbolic derivatives produce zero truncation error and avoid step-size $h$ numerical instability or catastrophic cancellation.)
