Quick Formative Checks

Readiness Check 1: Arithmetic Precedence

Question: Predict the output of 2 + 3 * 4^2 before typing it into MATLAB.

Answer: 50. MATLAB evaluates powers first ($4^2 = 16$), then multiplication ($3 \times 16 = 48$), then addition ($2 + 48 = 50$).

Readiness Check 2: Variable Assignment Syntax

Question: Which of the following commands assigns the value 10 to a variable named velocity?
A) 10 = velocity   |   B) velocity = 10;   |   C) velocity == 10

Answer: B. In MATLAB, assignment always places the variable on the left and the value/expression on the right. A produces a syntax error, and C is a relational equality test.

Part 1: Essential for Today (Live PC Lab Core)

The MATLAB Environment

When MATLAB opens, four primary panels organize your work:

  1. Current Folder: Shows files in your current working directory. Always verify that your active script is saved here.
  2. Command Window: Interactive console prompt (>>) for quick calculations, testing commands, and displaying outputs.
  3. Workspace: Memory monitor showing all active variables, their names, current values, sizes, and classes.
  4. Editor: Text editor where you create and edit reusable MATLAB script files (.m).

MATLAB as a Calculator

MATLAB evaluates standard arithmetic operations following algebraic precedence:

2 + 3       % Addition -> 5
5 - 2       % Subtraction -> 3
4 * 7       % Multiplication -> 28
10 / 4      % Division -> 2.5
2^8         % Exponentiation -> 256
Prediction Check: Why does 2 + 3 * 4 equal 14 rather than 20?

Variables and Assignment

Store computational results into memory using the assignment operator (=):

x = 10;
y = 5;
z = x + y   % Displays: z = 15

Case Sensitivity (Critical Grader Gotcha)

MATLAB is strictly case-sensitive. speed, Speed, and SPEED are three entirely different variables:

mass = 12.5;
Mass = 25.0;
% Checking Workspace confirms both variables exist independently!

Variable Naming Rules

  • Must begin with a letter (e.g. velocity, v1).
  • Can contain letters, numbers, and underscores (e.g. force_net_2).
  • Cannot start with a number (2velocity is INVALID).
  • Cannot contain spaces or special punctuation (force value and rate% are INVALID).
  • Cannot overwrite built-in keywords (avoid naming variables sin, cos, pi, i, j).

Suppressing Output with Semicolons

Ending a statement with a semicolon (;) executes the calculation silently without printing the result to the Command Window:

v = 25;       % Output suppressed (Workspace updated silently)
v = 25        % Output echoed to Command Window: v = 25

Best Practice: In script files, always terminate lines with semicolons unless you explicitly intend to print a value.

Managing Workspace and Screen

clear x        % Removes variable 'x' from Workspace
clear all      % Removes ALL variables from Workspace (resets memory)
clc            % Clears the Command Window text (does NOT delete variables)

Working with Scripts (.m Files)

Commands entered directly in the Command Window are temporary. To create permanent, repeatable calculations, create a Script:

  1. Click New Script on the Home tab (or press Ctrl+N / Cmd+N).
  2. Type your commands, comments, and formulas.
  3. Save the file with a valid name (e.g. lab1_intro.m).
  4. Click Run (or press F5) to execute the entire script.
% =========================================================
% 4004ENG Lab 1: First Engineering Script
% Calculates kinetic energy of an accelerating vehicle
% =========================================================
clear all; clc;

mass = 1200;            % Vehicle mass in kg
velocity = 28.5;        % Velocity in m/s

% Formula: KE = 0.5 * m * v^2
kinetic_energy = 0.5 * mass * velocity^2;

fprintf('Kinetic Energy: %.2f Joules\n', kinetic_energy);

Diagnostic Activity: Break and Repair Your Code

To master MATLAB troubleshooting, type each deliberate bug below into a script and observe the exact error message MATLAB produces:

  1. Bug 1 (Case Sensitivity): 
    time = 10;
distance = 50;
Speed = Distance / Time;  % Notice capital D and T!

    Error: Unrecognized function or variable 'Distance'.
    Fix: Change Distance / Time to distance / time.

  2. Bug 2 (Implicit Multiplication): 
    a = 4;
b = 2(a + 3);             % In algebra this means 2*(a+3)

    Error: Invalid expression. When calling a function or indexing a variable, use parentheses. Otherwise, use explicit operations.
    Fix: MATLAB requires explicit *: 2 * (a + 3).

  3. Bug 3 (Invalid Variable Name): 
    1st_reading = 9.81;

    Error: Invalid expression. Check for missing multiplication operator, missing or unbalanced delimiters...
    Fix: Variable names cannot start with a digit. Rename to reading_1st or reading_1.

Numerical Data Types

By default, every number in MATLAB is stored as a double (64-bit IEEE double-precision floating point), offering approximately 15–17 significant decimal digits of precision.

Output Display Formats

The format command changes how numbers are displayed in the Command Window; it does not change how they are stored in memory.

Command Example (x = 2/3) Description
format short 0.6667 Default: 4 decimal digits after the point
format long 0.666666666666667 Full 15 decimal digits precision display
format bank 0.67 Currency/2-digit decimal format
format rat 2/3 Rational fraction approximation
format shortEng 666.6667e-003 Engineering notation (exponent is multiple of 3)

Text Storage: Character Arrays vs Strings

  • Character Array (single quotes): tag = 'Sensor_A'; — Each character is an element in an array (e.g. tag(1) is 'S').
  • String (double quotes): msg = "Sensor_A"; — Treated as a single unified text scalar.

Help and Documentation Tools

help norm      % Quick command-line summary and syntax in Command Window
doc norm       % Opens full documentation window with worked examples

Pro Tip: Select any function name in the Editor or Command Window and press F1 to open context-sensitive documentation immediately.

Remote Lab Help & Troubleshooting (Microsoft Teams)

Working remotely during the PC lab? Here is how to diagnose and resolve immediate setup issues:

  • MATLAB Online session disconnected: Refresh your browser and log back in at matlab.mathworks.com. Files saved in MATLAB Drive are automatically preserved.
  • "Undefined function or variable": Check spelling and exact upper/lowercase capitalization. Ensure the variable was actually assigned earlier in the session.
  • Script does not execute: Make sure the script is saved in the Current Folder displayed on the left panel.
  • Command Window not accepting input: Check if a small "Busy" label is visible in the bottom-left status bar. Press Ctrl+C to interrupt any hanging loop.
