MATLAB Grader Expectations (Weeks 1 to 6)

Use this checklist for all weekly assignment problems and additional MATLAB Grader questions.

  1. Use the exact variable names requested in each problem template.
  2. Follow the required method when specified (for example symbolic vs numerical approach).
  3. Use element-wise operators in function handles when working with vectors (.*, ./, .^).
  4. Convert symbolic outputs to numeric values with double(...) when numeric values are requested.
  5. Keep units and physical meaning clear in engineering questions.
  6. If a result is geometrical area, ensure sign cancellation is handled correctly where needed.

Common Reasons Marks Are Lost

  • Wrong variable names (even when the maths is correct).
  • Correct formula but wrong MATLAB syntax for vectors/functions.
  • Returning symbolic values where numeric outputs are required.
  • Missing intermediate variables that are explicitly requested.
