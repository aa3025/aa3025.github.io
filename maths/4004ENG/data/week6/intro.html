Week 6: Complex Numbers & Numerical Methods

Why This Matters in Engineering

This capstone module brings together two indispensable pillars of modern engineering computation:

  • Complex Numbers ($z = a + bi = re^{i\theta}$): Used universally in AC electrical circuits (impedance $Z = R + j\omega L$), vibration and damping analysis in civil structures, aerodynamic flutter in aircraft, and frequency response in feedback control systems.
  • Numerical Methods: In the real world, most engineering equations cannot be solved with a neat analytical pencil-and-paper formula. Numerical algorithms — such as Newton-Raphson for non-linear root finding and Euler's Method for dynamic system simulations — enable computers to find high-precision solutions iteratively.

Quick Formative Checks

Readiness Check 1: Imaginary Unit in MATLAB

Question: Why is z = 3 + 4*1i safer in MATLAB than z = 3 + 4*i?

Answer: If a script uses i as a loop counter (e.g. for i = 1:10), the variable i gets overwritten with an integer, breaking subsequent complex calculations. 1i or 1j is hardcoded into MATLAB's lexical parser and can never be overwritten.

Readiness Check 2: Newton-Raphson Division by Zero

Question: What happens to the Newton update $x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$ if the initial guess is placed at a local maximum or minimum of $f(x)$?

Answer: At a local extremum, $f'(x_n) = 0$. Division by zero causes the update step to explode to $\pm\infty$ or produce NaN. Always choose an initial guess where the derivative is safely non-zero.

Quick Reference: Complex Numbers & Numerical Methods

Complex Number Tools in MATLAB

MATLAB uses 1i (or 1j) for the imaginary unit. Always use 1i to avoid variable collision:

z = 3 + 4*1i;
zr = real(z);          % Real part: 3
zi = imag(z);          % Imaginary part: 4
r  = abs(z);           % Modulus / magnitude: 5
th = angle(z);         % Phase angle in radians: 0.9273
th_deg = rad2deg(th);  % Phase angle in degrees: 53.13 deg
zc = conj(z);          % Complex conjugate: 3 - 4*1i

Polar and Exponential Forms

For any complex number $z = a + bi$:

\[z = r(\cos\theta + i\sin\theta) = re^{i\theta}\]

where $r = |z| = \sqrt{a^2 + b^2}$ and $\theta = \text{atan2}(b, a)$. In MATLAB:

z_reconstructed = r * exp(1i * th);  % Matches z within 1e-15

De Moivre's Theorem for Powers and Roots

For powers: $(re^{i\theta})^n = r^n e^{in\theta}$.

For the $n$-th roots of $w = re^{i\theta}$, the $n$ distinct roots spaced evenly around a circle are:

\[z_k = r^{1/n} \exp\left(i\frac{\theta + 2\pi k}{n}\right), \quad k = 0, 1, \dots, n-1\]

Numerical Algorithms

1. Newton-Raphson Iteration ($f(x) = 0$)

\[x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}\]

Stop iterating when $|x_{n+1} - x_n| < \text{tolerance}$ or after a maximum number of steps.

2. Euler's Method for First-Order ODEs ($\frac{dy}{dt} = f(t, y)$)

\[y_{i+1} = y_i + h \cdot f(t_i, y_i)\]

where $h$ is the time step size ($\Delta t$). Smaller $h$ reduces local truncation error but increases computation time. If $h$ is too large, numerical instability occurs.

Worked Examples

Example 1: Complex Arithmetic and Conjugate

z1 = 3 + 4*1i;
z2 = 1 - 2*1i;

z_sum  = z1 + z2;     % 4 + 2i
z_prod = z1 * z2;     % (3*1 - 4*(-2)) + (3*(-2) + 4*1)i = 11 - 2i
z_quot = z1 / z2;     % -1 + 2i
z1_conj = conj(z1);   % 3 - 4i

Example 2: Polar to Exponential Reconstruction

z = -1 + 1*1i;
r = abs(z);                    % sqrt(2) = 1.4142
theta = angle(z);              % 3*pi/4 = 2.3562 rad (135 deg)
z_exp = r * exp(1i * theta);   % Reconstructs -1 + 1i

Example 3: Five Roots of $z^5 = 32$ and Argand Plot

w = 32;
r_w = abs(w);
theta_w = angle(w);            % 0 for positive real 32

z_roots = zeros(1, 5);
for k = 0:4
    z_roots(k+1) = r_w^(1/5) * exp(1i * (theta_w + 2*pi*k) / 5);
end

% Sum of roots of unity / symmetric polynomial is zero
sum_roots = sum(z_roots);      % Approximately 0 (within 1e-15)

Example 4: Newton-Raphson Iteration

f = @(x) x.^2 - 2;             % Solve x^2 = 2 -> sqrt(2)
df = @(x) 2*x;

x = 1.5;                       % Initial guess
for i = 1:5
    x = x - f(x) / df(x);
end
x_final = x;
err = abs(x_final - sqrt(2));  % < 1e-12 after 5 iterations!

Example 5: Euler Simulation of Free Fall with Drag

m = 80; g = 9.81; c = 15;
v0 = 0; h = 0.1; T = 20;
N = T / h;

f = @(t, v) g - (c/m)*v;
v = v0;
t = 0;
for i = 1:N
    v = v + h * f(t, v);
    t = t + h;
end
v_final = v;
v_term = (m * g) / c;          % Analytical terminal velocity: 52.32 m/s
diff_terminal = abs(v_final - v_term);

Common Errors & Troubleshooting

Error / Symptom Likely Cause Fix
Wrong complex result after multiplication/division Typo in sign or missing 1i factor Re-check algebra and use 1i explicitly (avoid bare i)
Angle seems incorrect in degrees angle() returns radians Convert with rad2deg(...)
Reconstructed z_exp is not exactly equal to z Floating-point rounding Compare with tolerance: abs(z - z_exp) < 1e-12
Newton update fails or explodes to infinity Initial guess too far, or derivative near zero Choose a better initial guess and verify $f'(x) \neq 0$
Euler solution oscillates or blows up Step size $h$ too large for the system time constant Reduce $h$ (e.g. from $0.5$ to $0.05$) and re-run
Terminal velocity comparison seems wrong sign Using signed difference instead of magnitude Use abs(v_final - v_term) for magnitude of error

Remote Lab Help: Newton-Raphson & ODE Loops

  • Loop runs forever (script freezes): Check your loop termination condition. In MATLAB, press Ctrl+C in the Command Window to immediately abort execution.
  • "Subscript indices must either be real positive integers or logicals": In MATLAB, arrays start at index 1! When writing loops over $k=0, \dots, n-1$, store into array index z_roots(k+1).
  • Complex values in Euler method: Check for negative values inside square roots in your ODE function.
