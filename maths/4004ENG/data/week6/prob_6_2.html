Problem 2: Polar and Exponential Forms Live Core

Learning Outcomes

  • Calculate the modulus (magnitude $r$) and argument (phase $\theta$) of a complex number using abs() and angle().
  • Convert phase angles between radians and degrees using rad2deg().
  • Represent and reconstruct complex numbers in exponential polar form using Euler's formula ($z = r e^{i\theta}$).
  • Compute integer powers of complex numbers using De Moivre's theorem ($z^n = r^n e^{in\theta}$).

Description

In AC circuits and frequency response modeling, engineering quantities are usually expressed in polar/phasor coordinates (magnitude and phase angle). This exercise demonstrates how to convert between Cartesian and exponential polar forms in MATLAB.

Required Grader Variables

Variable Name Expected Type Dimension Description
z double (complex) $1 \times 1$ scalar Complex number $-1 + 1i$
r double $1 \times 1$ scalar Modulus $|z| = \sqrt{a^2 + b^2}$ via abs(z)
theta double $1 \times 1$ scalar Phase angle in radians via angle(z)
theta_deg double $1 \times 1$ scalar Phase angle in degrees via rad2deg(theta)
z_exp double (complex) $1 \times 1$ scalar Reconstructed complex number $r e^{i\theta}$
z5 double (complex) $1 \times 1$ scalar Fifth power $z^5$
Prediction Prompt: For $z = -1 + 1i$, since $\text{Re}(z) = -1 < 0$ and $\text{Im}(z) = +1 > 0$, in which quadrant of the complex plane does $z$ lie? (Quadrant II: $\theta = 135^\circ$ or $3\pi/4 \approx 2.356$ radians).

Problem Tasks

Complete the following tasks in prob_6_2.m.

Part A — Magnitude and Phase
Given $z = -1+1i$, store it as z and calculate its magnitude r (using abs()) and phase angle theta in radians (using angle()).

Part B — Convert to Degrees
Convert theta to degrees, storing the result in theta_deg using rad2deg().

Part C — Exponential Form
Reconstruct the complex number using Euler's formula, $z = re^{i\theta}$, storing the result in z_exp = r * exp(1i * theta).

Part D — Powers via De Moivre's Theorem
Calculate z5 = z^5, and observe how easily powers are calculated once a complex number is expressed in exponential form.

Staged Hints

Hint 1: Concept Hint (Euler's Formula & Polar Form)

Every complex number can be written as $z = a + bi = r(\cos\theta + i\sin\theta) = r e^{i\theta}$, where $r = \sqrt{a^2 + b^2}$ and $\theta = \text{atan2}(b, a)$. Raising to a power $n$ yields $(re^{i\theta})^n = r^n e^{in\theta}$.

Hint 2: MATLAB Syntax Hint

Use abs(z) for magnitude and angle(z) for phase (returns radians in $[-\pi, \pi]$). Convert using rad2deg(theta). Reconstruct using r * exp(1i * theta).

Hint 3: Code Skeleton 
% Part A
z = -1 + 1*1i;
r = abs(z);
theta = angle(z);

% Part B
theta_deg = rad2deg(theta);

% Part C
z_exp = r * exp(1i * theta);

% Part D
z5 = z^5;

Self-Check & Expected Properties

  • r is $\sqrt{(-1)^2 + 1^2} = \sqrt{2} \approx 1.4142$.
  • theta should be $3\pi/4 \approx 2.3562$ radians, and theta_deg must equal $135.0^\circ$.
  • abs(z - z_exp) must be less than $10^{-14}$.
  • Using De Moivre: $z^5 = (\sqrt{2})^5 e^{i(5 \times 135^\circ)} = 4\sqrt{2} e^{i(675^\circ)} = 4\sqrt{2} e^{-i(45^\circ)} = 4 - 4i$. Check that z5 equals $4 - 4i$!

Engineering Reflection

Why do electrical engineers convert sinusoidal voltages $v(t) = V_m \cos(\omega t + \phi)$ into complex phasors $\mathbf{V} = V_m e^{i\phi}$ when solving RLC circuits? (Answer: It transforms differential equations into simple complex algebraic multiplications.)
