Problem 4: Newton-Raphson Method Independent Consolidation

Learning Outcomes

  • Create vectorized function handles for equations and analytical derivatives.
  • Implement iterative numerical algorithms using for loops and recursive state updates.
  • Monitor convergence criteria and calculate absolute error ($|x_{\text{approx}} - x_{\text{true}}|$).
  • Identify divergence conditions (such as initial guess placed near $f'(x) \approx 0$).

Description

Finding the roots of non-linear equations is a universal engineering challenge. When analytical inversion is impossible, iterative numerical algorithms like Newton-Raphson provide quadratic convergence, doubling the number of correct decimal digits with every iteration.

Required Grader Variables

Variable Name Expected Type Dimension Description
f function_handle handle Function handle @(x) x.^2 - 2
df function_handle handle Derivative handle @(x) 2*x
x0 double $1 \times 1$ scalar Initial guess $x_0 = 1.5$
x1 double $1 \times 1$ scalar Estimate after 1 step via $x_0 - f(x_0)/f'(x_0)$
x_final double $1 \times 1$ scalar Estimate after 5 loop iterations
err double $1 \times 1$ scalar Absolute error $|x_{\text{final}} - \sqrt{2}|$
Prediction Prompt: Calculate the first Newton update from $x_0 = 1.5$ by hand: $x_1 = 1.5 - \frac{1.5^2 - 2}{2(1.5)} = 1.5 - \frac{0.25}{3.0} = 1.5 - 0.08333 = 1.41667$. Notice that after just one step, the error relative to $\sqrt{2} \approx 1.41421$ is already under $0.0025$!

Problem Tasks

Complete the following tasks in prob_6_4.m. Recall the Newton-Raphson update equation: $$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$

Part A — Define the Function and Derivative
Find the positive root of $f(x) = x^2 - 2$ (the true root is $\sqrt{2}$). Create function handles f = @(x) x.^2 - 2 and df = @(x) 2*x.

Part B — One Iteration
Starting from an initial guess x0 = 1.5, calculate the next value x1 using a single Newton-Raphson update.

Part C — Five Iterations in a Loop
Implement a for loop that performs 5 iterations starting from x0, updating x each cycle, and storing the final result in x_final.

Part D — Check the Error
Calculate the absolute error err = abs(x_final - sqrt(2)).

Part E — Visualisation (Optional Extension)
Store the error at each step and plot iteration number vs $\log_{10}(\text{error})$ to observe the rapid quadratic convergence of the method.

Staged Hints

Hint 1: Concept Hint (Newton-Raphson Method)

Newton's method approximates the function by its tangent line at current guess $x_n$. The $x$-intercept of this tangent line becomes the next improved guess $x_{n+1}$. Near a simple root, the error is squared at each step ($e_{n+1} \approx C e_n^2$), producing quadratic convergence.

Hint 2: MATLAB Syntax Hint

Define handles with @(x). In the loop, update the variable in place: x = x - f(x) / df(x);. After the loop completes, assign x_final = x;.

Hint 3: Code Skeleton 
% Part A
f = @(x) x.^2 - 2;
df = @(x) 2*x;

% Part B
x0 = 1.5;
x1 = x0 - f(x0) / df(x0);

% Part C
x = x0;
for i = 1:5
    x = x - f(x) / df(x);
end
x_final = x;

% Part D
err = abs(x_final - sqrt(2));

Self-Check & Expected Properties

  • x1 must equal $1.416666...$ (or $17/12$).
  • x_final should equal approximately $1.41421356...$.
  • err after 5 iterations should be less than $10^{-12}$ (machine precision limit).

Engineering Reflection

Why can Newton-Raphson fail if the derivative at an iterate is near zero ($f'(x_n) \approx 0$)? (Answer: The tangent line becomes nearly horizontal; its $x$-intercept shoots off to $\pm\infty$, causing the algorithm to diverge or enter an infinite cycle.)
