Problem 1: Complex Number Basics Live Core

Learning Outcomes

  • Define complex numbers in MATLAB using Cartesian notation and the 1i imaginary unit.
  • Execute fundamental complex arithmetic (addition, multiplication, division).
  • Extract component parts (real and imaginary components) using real() and imag().
  • Compute the complex conjugate using conj().

Description

Complex numbers are used extensively in AC electrical circuits, control engineering, and vibration mechanics. This exercise introduces MATLAB's lexical syntax for manipulating complex variables in the Cartesian plane.

Prediction Prompt: Multiply $z_1 = 3 + 4i$ and $z_2 = 1 - 2i$ by hand: $(3)(1) - (4)(-2) + [3(-2) + 4(1)]i = 3 + 8 + (-6 + 4)i = 11 - 2i$. Note that $i^2 = -1$ flips the sign of the product of imaginary parts!

Problem Tasks

Complete the following tasks in prob_6_1.m.

Part A — Define Complex Numbers
Define two complex numbers: z1 = 3 + 4*1i and z2 = 1 - 2*1i. (Using 1i is recommended to avoid collisions with loop variables).

Part B — Arithmetic Operations
Calculate:

  1. z_sum = z1 + z2
  2. z_prod = z1 * z2
  3. z_quot = z1 / z2

Part C — Real and Imaginary Parts
Extract the real part real_z1 and imaginary part imag_z1 of z1 using real() and imag().

Part D — Complex Conjugate
Calculate the complex conjugate z1_conj of z1 using conj().

Staged Hints

Hint 1: Concept Hint (Complex Numbers)

A complex number has the form $z = a + bi$ where $i = \sqrt{-1}$. Addition adds real and imaginary components separately. The conjugate is $\bar{z} = a - bi$. Dividing by $z_2$ multiplies numerator and denominator by $\bar{z}_2$: $\frac{z_1}{z_2} = \frac{z_1 \bar{z}_2}{|z_2|^2}$.

Hint 2: MATLAB Syntax Hint

MATLAB natively supports complex numbers without requiring toolboxes. Use 1i for the imaginary unit: 3 + 4*1i. Built-in functions real(z), imag(z), and conj(z) extract components.

Hint 3: Code Skeleton 
% Part A
z1 = 3 + 4*1i;
z2 = 1 - 2*1i;

% Part B
z_sum = z1 + z2;
z_prod = z1 * z2;
z_quot = z1 / z2;

% Part C
real_z1 = real(z1);
imag_z1 = imag(z1);

% Part D
z1_conj = conj(z1);

Self-Check & Expected Properties

  • z_sum should be $4 + 2i$.
  • z_prod should be $11 - 2i$.
  • z_quot is $\frac{(3+4i)(1+2i)}{1^2 + (-2)^2} = \frac{-5 + 10i}{5} = -1 + 2i$.
  • real_z1 is 3, imag_z1 is 4, and z1_conj is $3 - 4i$.

Engineering Reflection

In AC circuit analysis, why is electrical impedance defined as a complex number $Z = R + jX$? (Answer: The real part represents resistive energy dissipation, and the imaginary reactance represents magnetic and electrostatic energy storage in inductors and capacitors.)
