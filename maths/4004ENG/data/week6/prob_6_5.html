Problem 5: Physics Simulation - Free Fall with Drag Optional Stretch

Learning Outcomes

  • Model dynamic physical systems (free fall with aerodynamic drag) using first-order ordinary differential equations (ODEs).
  • Implement Euler's forward time-stepping algorithm to numerically simulate velocity evolution over time.
  • Determine and calculate the theoretical asymptotic terminal velocity ($v_{\text{term}} = mg/c$).
  • Analyze how numerical approximations approach steady-state physical limits.

Description

In this capstone engineering simulation, you will apply Euler's numerical integration method to simulate a real-world aerodynamic problem: predicting the velocity profile of an 80 kg skydiver falling under gravity and turbulent atmospheric drag until terminal velocity is reached.

Prediction Prompt: When a skydiver reaches terminal velocity, acceleration drops to zero ($dv/dt = 0$). From $g - \frac{c}{m}v_{\text{term}} = 0$, predict $v_{\text{term}}$: $v_{\text{term}} = \frac{mg}{c} = \frac{80 \times 9.81}{15} = 52.32\text{ m/s}$ (approx. $188\text{ km/h}$).

Problem Tasks

Complete the following tasks in prob_6_5.m. A skydiver ($m=80$ kg) falls under gravity ($g=9.81\ \text{m/s}^2$) with drag force $F_d = -cv$ ($c=15$ kg/s), giving the ODE: $$\frac{dv}{dt} = g - \frac{c}{m}v$$

Part A — Set Physical Parameters
Set m = 80, g = 9.81, c = 15, initial velocity v0 = 0, step size h = 0.1, and total duration T = 20. Calculate the number of steps N = T / h.

Part B — Define the ODE Function Handle
Define the function handle f = @(t, v) g - (c/m)*v.

Part C — Implement Euler's Method
Use a for loop to advance velocity v forward N steps using Euler's algorithm: $$v_{i+1} = v_i + h \cdot f(t_i, v_i)$$ Store the velocity at the end of the simulation ($t = 20$ s) in v_final.

Part D — Compare with Terminal Velocity
Calculate theoretical terminal velocity v_term = (m*g)/c and the absolute difference diff_terminal = abs(v_final - v_term).

Part E — Visualisation (Optional Extension)
Store velocity values at each step into a vector v_history, then plot velocity vs time overlaid with a dashed horizontal line at v_term.

Staged Hints

Hint 1: Concept Hint (Euler's Method for ODEs)

Euler's method approximates the continuous derivative with a finite difference: $\frac{dv}{dt} \approx \frac{v_{i+1} - v_i}{h}$. Rearranging gives the explicit forward step: $v_{i+1} = v_i + h f(t_i, v_i)$. As $t \to \infty$, velocity asymptotically approaches the steady-state value where $f(t, v) = 0$.

Hint 2: MATLAB Syntax Hint

Initialize v = v0; t = 0; before the loop. Inside for i = 1:N, update v = v + h * f(t, v); and t = t + h;. After the loop, save v_final = v;.

Hint 3: Code Skeleton 
% Part A
m = 80;
g = 9.81;
c = 15;
v0 = 0;
h = 0.1;
T = 20;
N = T / h;

% Part B
f = @(t, v) g - (c/m)*v;

% Part C
v = v0;
t = 0;
for i = 1:N
    v = v + h * f(t, v);
    t = t + h;
end
v_final = v;

% Part D
v_term = (m * g) / c;
diff_terminal = abs(v_final - v_term);

Self-Check & Expected Properties

  • N must be 200 steps.
  • v_term is $(80 \times 9.81) / 15 = 52.32$ m/s.
  • v_final after 20 seconds is approximately $51.13$ m/s (approaching $98\%$ of terminal velocity).
  • diff_terminal should be approximately $1.19$ m/s.

Engineering Reflection

What happens if you run Euler's simulation with an excessively large time step such as $h = 15.0$ seconds? (Answer: Numerical instability occurs! The update overshoots terminal velocity wildly and oscillates unstably towards $\pm\infty$. Time step $h$ must be significantly smaller than the system's dynamic time constant $\tau = m/c = 80/15 \approx 5.33\text{ s}$.)
