Problem 2: Matrix Multiplication Live Core

Learning Outcomes

  • Distinguish between linear algebraic matrix multiplication (*) and element-wise multiplication (.*).
  • Understand and verify the inner dimension matching condition ($n_A = m_B$).
  • Demonstrate and explain the non-commutative property of matrix multiplication ($A \times B \neq B \times A$).

Description

Matrix multiplication is an essential operation in engineering simulation, but its mathematical rules are completely different from scalar arithmetic. In this problem, you will explore matrix product rules, dimension requirements, and non-commutativity.

Required Grader Variables

Variable Name Expected Type Dimension Description
A, B double $2 \times 2$ Matrices $[1, 2; 3, 4]$ and $[5, 6; 7, 8]$
C double $2 \times 2$ Matrix product $A \times B$ via A * B
D double $2 \times 3$ Matrix $[1, 0, 5; 2, -1, 3]$
E double $2 \times 3$ Product $A \times D$ (verifying compatibility)
F double $2 \times 2$ Element-wise product $A \odot B$ via A .* B
G double $2 \times 2$ Matrix product $A \times B$ (matches C)
H double $2 \times 2$ Reversed product $B \times A$
Prediction Prompt: Calculate the top-left element of $A \times B$: $(1 \times 5) + (2 \times 7) = 19$. In contrast, what is the top-left element of element-wise $A .* B$? ($1 \times 5 = 5$).

Problem Tasks

Complete the following tasks in prob_3_2.m.

Part A — Standard Matrix Multiplication
Given $A = [1, 2; 3, 4]$ and $B = [5, 6; 7, 8]$, store them as A and B and calculate the matrix product C = A * B.

Part B — Multiplicability Check
Given A ($2 \times 2$) and a $2 \times 3$ matrix $D = [1, 0, 5; 2, -1, 3]$, store D and calculate the product E = A * D. Note how the result dimensions $(2 \times 3)$ relate to the dimensions of A and D.

Part C — Element-wise vs Matrix Multiplication

  1. Calculate the element-wise product F = A .* B.
  2. Calculate the matrix product G = A * B (this should match C from Part A).

Part D — Non-Commutativity
Calculate H = B * A and compare it with C. Confirm that, in general for matrices, $A \times B \neq B \times A$.

Staged Hints

Hint 1: Concept Hint (Matrix Multiplication Rules)

To multiply $A_{m \times k}$ by $B_{k \times n}$, the number of columns in $A$ must equal the number of rows in $B$. The result has size $m \times n$. Entry $(i, j)$ is the dot product of row $i$ of $A$ and column $j$ of $B$. Because order matters, matrix multiplication is non-commutative ($AB \neq BA$).

Hint 2: MATLAB Syntax Hint

Use the standard asterisk * for matrix multiplication: C = A * B;. For element-by-element multiplication where corresponding cells are multiplied, prepend a dot: F = A .* B;.

Hint 3: Code Skeleton 
% Part A
A = [1, 2; 3, 4];
B = [5, 6; 7, 8];
C = A * B;

% Part B
D = [1, 0, 5; 2, -1, 3];
E = A * D;

% Part C
F = A .* B;
G = A * B;

% Part D
H = B * A;

Self-Check & Expected Properties

  • C should be [19, 22; 43, 50].
  • size(E) must be [2, 3], with values [5, -2, 11; 11, -4, 27].
  • F must be [5, 12; 21, 32] (clearly different from C!).
  • H is [23, 34; 31, 46] $\neq$ C, proving non-commutativity.

Engineering Reflection

Why does the non-commutativity of matrix multiplication matter when programming a robotic arm or flight simulator? (Answer: Rotating $90^\circ$ about the pitch axis followed by $90^\circ$ about the yaw axis puts the aircraft into an entirely different orientation than doing yaw first and pitch second!)
