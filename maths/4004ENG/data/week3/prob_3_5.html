Problem 5: Geometric Transformations Optional Stretch

Learning Outcomes

  • Define 2D geometric shapes as coordinate matrices with vertices as column vectors.
  • Apply scaling transformation matrices to enlarge or compress geometries.
  • Implement 2D rotation matrices using trigonometric functions.
  • Understand the linear algebraic principles underlying computer graphics, CAD modeling, and robotic kinematics.

Description

Matrices are the computational engine behind computer-aided design (CAD), game engines, and robotic kinematics. In this capstone problem for Week 3, you will define a 2D geometric shape and apply scaling and rotation matrices to manipulate its position and orientation in the Cartesian plane.

Required Grader Variables

Variable Name Expected Type Dimension Description
P double $2 \times 3$ Triangle vertices as columns: $[0, 2, 1; 0, 0, 2]$
S double $2 \times 2$ Scaling matrix $[2, 0; 0, 2]$
P_scaled double $2 \times 3$ Scaled shape $S \times P$
theta double $1 \times 1$ scalar Rotation angle in radians (from $45^\circ$)
R double $2 \times 2$ Rotation matrix $[\cos\theta, -\sin\theta; \sin\theta, \cos\theta]$
P_rotated double $2 \times 3$ Rotated shape $R \times P$
Prediction Prompt: Why must the vertices of the shape be stored as columns $[x; y]$ in $P$ ($2 \times 3$) rather than rows ($3 \times 2$)? (Because the $2 \times 2$ transformation matrix pre-multiplies the coordinates: $P_{\text{new}} = T_{2 \times 2} P_{2 \times 3}$. If $P$ had 3 rows, inner dimensions would not match!).

Problem Tasks

Complete the following tasks in prob_3_5.m.

Part A — Define a Shape
Define a triangle with vertices at $(0,0)$, $(2,0)$, and $(1,2)$. Store the vertices as columns in matrix P = [0, 2, 1; 0, 0, 2].

Part B — Scaling Transformation
Create a scaling matrix S that doubles the size of the shape in both $x$ and $y$: $S = [s_x, 0; 0, s_y]$ with $s_x = s_y = 2$. Apply the transformation: P_scaled = S * P.

Part C — Rotation Transformation
Create a rotation matrix R to rotate the original shape P by 45° counter-clockwise (use theta = deg2rad(45)): $$R = \begin{bmatrix}\cos\theta & -\sin\theta\\ \sin\theta & \cos\theta\end{bmatrix}$$ Apply the transformation: P_rotated = R * P.

Part D — Visualisation (Optional Extension)
Plot the original triangle P in blue and the rotated triangle P_rotated in red on the same axes. Remember to repeat the first vertex at the end (e.g. P(1, [1:3, 1])) to close the triangle perimeter, then set axis equal.

Staged Hints

Hint 1: Concept Hint (Linear Transformations)

A linear transformation transforms coordinate vectors $\mathbf{x}' = T\mathbf{x}$. By placing multiple points into a coordinate matrix as columns $P = [\mathbf{p}_1, \mathbf{p}_2, \dots, \mathbf{p}_n]$, pre-multiplying by matrix $T$ applies the transformation simultaneously to all points in a single vectorised operation: $P' = TP$.

Hint 2: MATLAB Syntax Hint

Convert angles using theta = deg2rad(45);. Use standard trigonometric functions cos(theta) and sin(theta) to build $R$. Multiply using R * P.

Hint 3: Code Skeleton 
% Part A
P = [0, 2, 1; 
     0, 0, 2];

% Part B
S = [2, 0; 
     0, 2];
P_scaled = S * P;

% Part C
theta = deg2rad(45);
R = [cos(theta), -sin(theta); 
     sin(theta),  cos(theta)];
P_rotated = R * P;

Self-Check & Expected Properties

  • size(P), size(P_scaled), and size(P_rotated) must all be $2 \times 3$.
  • P_scaled should be [0, 4, 2; 0, 0, 4].
  • The origin $(0, 0)$ remains at $(0, 0)$ under both scaling and rotation (because linear transformations preserve the origin).

Engineering Reflection

In autonomous vehicles and robotic arm kinematics, how are combined transformations (scaling, rotation, translation) concatenated into a single matrix? (Answer: By multiplying the individual transformation matrices in reverse sequence $T_{\text{net}} = T_n \dots T_2 T_1$, known as homogeneous transformation matrices.)
