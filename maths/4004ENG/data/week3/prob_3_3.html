Problem 3: Determinant and Inverse Live Core

Learning Outcomes

  • Calculate the determinant of 2x2 and 3x3 matrices using the built-in det() function.
  • Compute the inverse of a non-singular square matrix using inv().
  • Verify the fundamental identity property of matrix inverses ($B \times B^{-1} = I$).
  • Understand the engineering implications of matrix singularity ($\det = 0$).

Description

The determinant and inverse are crucial for solving engineering systems of equations. In this problem, you will calculate determinants, compute inverses, and verify the identity matrix product.

Required Grader Variables

Variable Name Expected Type Dimension Description
A double $2 \times 2$ Matrix $[1, 2; 3, 4]$
det_A double $1 \times 1$ scalar Determinant of $A$ via det(A)
B double $3 \times 3$ Matrix $[1, 2, 3; 0, 1, 4; 5, 6, 0]$
det_B double $1 \times 1$ scalar Determinant of $B$ via det(B)
B_inv double $3 \times 3$ Matrix inverse of $B$ via inv(B)
I_check double $3 \times 3$ Product $B \times B^{-1}$ ($\approx$ identity matrix)
Prediction Prompt: Calculate $\det(A)$ by hand: $ad - bc = (1 \times 4) - (2 \times 3) = 4 - 6 = -2$. Since $\det(A) \neq 0$, does $A^{-1}$ exist?

Problem Tasks

Complete the following tasks in prob_3_3.m.

Part A — Determinant of a 2x2 Matrix
Given $A = [1, 2; 3, 4]$, store it as A and calculate its determinant det_A using det().

Part B — Determinant of a 3x3 Matrix
Given $B = [1, 2, 3; 0, 1, 4; 5, 6, 0]$, store it as B and calculate its determinant det_B.

Part C — Matrix Inverse
Calculate the inverse of B and store it in B_inv using inv().

Part D — Identity Verification
Verify the property $B \times B^{-1} = I$ by computing I_check = B * B_inv. The result should equal the $3\times3$ identity matrix (within machine precision).

Staged Hints

Hint 1: Concept Hint (Inverses and Identity)

A square matrix is invertible if and only if its determinant is non-zero ($\det(M) \neq 0$). Multiplying any invertible matrix by its inverse yields the identity matrix $I$ (with 1s on the main diagonal and 0s elsewhere): $M M^{-1} = M^{-1} M = I$.

Hint 2: MATLAB Syntax Hint

Use det(A) to compute the determinant. Use inv(B) to compute the inverse matrix. To verify, use standard matrix multiplication: I_check = B * B_inv;.

Hint 3: Code Skeleton 
% Part A
A = [1, 2; 3, 4];
det_A = det(A);

% Part B
B = [1, 2, 3; 0, 1, 4; 5, 6, 0];
det_B = det(B);

% Part C
B_inv = inv(B);

% Part D
I_check = B * B_inv;

Self-Check & Expected Properties

  • det_A must equal exactly -2.
  • det_B is $1(0 - 24) - 2(0 - 20) + 3(0 - 5) = -24 + 40 - 15 = 1$.
  • I_check should match eye(3) to within $10^{-14}$.

Engineering Reflection

If the global stiffness matrix $K$ of a structural truss has $\det(K) = 0$, what does this indicate physically about the structure? (Answer: The structure is unstable or contains an unconstrained rigid-body mechanism; it can collapse or move freely under load!)
