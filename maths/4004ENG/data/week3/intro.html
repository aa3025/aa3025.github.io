Week 3: Matrices & Systems of Equations

Why This Matters in Engineering

Matrices are the backbone of large-scale engineering computation. In civil and structural engineering, global stiffness matrices ($K\mathbf{u} = \mathbf{f}$) relate forces to structural deflections in skyscrapers and bridges. In electrical engineering, nodal analysis models complex AC/DC circuits through conductance matrices. In robotics and computer graphics, $2\text{D}$ and $3\text{D}$ transformation matrices rotate, translate, and scale CAD geometries and robotic arms in real time.

This module advances your linear algebra skills from single vectors to multi-dimensional matrices, covering matrix arithmetic, determinants, inverses, and solving simultaneous linear systems $A\mathbf{x} = \mathbf{b}$ using MATLAB's numerically robust backslash operator (\).

Quick Formative Checks

Readiness Check 1: Matrix Multiplication Dimension Compatibility

Question: Can a matrix $A$ of size $3 \times 2$ be multiplied by a matrix $B$ of size $2 \times 4$? If so, what is the size of the product $C = AB$?

Answer: Yes. The inner dimensions match ($2 = 2$). The resulting matrix $C$ has outer dimensions: $3 \text{ rows} \times 4 \text{ columns}$.

Readiness Check 2: Element-wise vs Matrix Multiplication

Question: What is the difference in MATLAB between A * B and A .* B?

Answer: A * B performs standard linear algebraic matrix multiplication (row-by-column dot products). A .* B multiplies corresponding elements individually and requires both matrices to have the exact same dimensions.

Quick Reference: Matrix Mathematics

What is a Matrix?

A matrix is a rectangular array of numbers arranged in rows and columns. A matrix with $m$ rows and $n$ columns is described as $m \times n$. In MATLAB:

  • Commas or spaces separate entries in the same row.
  • Semicolons ; end a row and begin the next row.
A = [1, 2; 3, 4]  % 2x2 square matrix
v = [1, 2, 3]     % 1x3 row vector
w = [1; 2; 3]     % 3x1 column vector

Matrix Generation Tools

Command Description Example
zeros(m, n) Creates an $m \times n$ matrix of zeros Z = zeros(3, 2);
ones(m, n) Creates an $m \times n$ matrix of ones O = ones(2, 4);
eye(n) Creates an $n \times n$ identity matrix with 1s on main diagonal I = eye(3);
size(A) Returns dimensions vector [rows, cols] [r, c] = size(A);
numel(A) Returns total number of elements ($r \times c$) N = numel(A);

Matrix Operations & Solving Systems

Operation Formula / Method MATLAB Syntax Notes
Matrix Product $C_{ij} = \sum_k A_{ik}B_{kj}$ C = A * B; Requires inner dimensions to agree ($n_A = m_B$)
Element-Wise Mult $D_{ij} = A_{ij} B_{ij}$ D = A .* B; Requires identical size for $A$ and $B$
Transpose $A^T$ A_trans = A'; Swaps rows and columns
Determinant $\det(A)$ d = det(A); Scalar; non-zero indicates invertibility
Matrix Inverse $A^{-1}$ ($A A^{-1} = I$) A_inv = inv(A); Requires $A$ to be square and $\det(A) \neq 0$
Solve $A\mathbf{x}=\mathbf{b}$ $\mathbf{x} = A^{-1}\mathbf{b}$ x = A \ b; Preferred backslash operator (Gaussian elimination)

Worked Examples

Example 1: Matrix Multiplication vs Element-wise Multiplication

A = [1, 2; 3, 4];
B = [5, 6; 7, 8];

% Linear algebraic matrix multiplication
C = A * B;   % Returns: [19, 22; 43, 50]

% Element-wise multiplication
D = A .* B;  % Returns: [5, 12; 21, 32]
Prediction Prompt: Before running A * B, verify the top-left entry by hand: $(1 \times 5) + (2 \times 7) = 5 + 14 = 19$.

Example 2: Determinant and Inverse Verification

A = [4, 7; 2, 6];
d = det(A);        % det(A) = 4*6 - 7*2 = 24 - 14 = 10

if abs(d) > 1e-10
    A_inv = inv(A);
    % Verify: A * A_inv should equal eye(2)
    identity_check = A * A_inv;
else
    error('Matrix is singular and cannot be inverted.');
end

Example 3: Solving a 3-Variable Linear System

Solve the simultaneous system: \[2x + y + z = 8\] \[-3x - y + 2z = -11\] \[-2x + y + 2z = -3\]

A = [ 2,  1, 1;
     -3, -1, 2;
     -2,  1, 2];
b = [8; -11; -3];  % Column vector

% Backslash solve
x_sol = A \ b;     % Returns: [2; 3; 1] (i.e. x=2, y=3, z=1)

Example 4: 2D Rotation of a Shape

% Unit square corners stored as columns [x; y]
square = [0, 1, 1, 0; 
          0, 0, 1, 1];

% 45-degree rotation matrix
theta = deg2rad(45);
R = [cos(theta), -sin(theta); 
     sin(theta),  cos(theta)];

% Apply transformation
rotated_square = R * square;

Remote Lab Help: Matrix Common Errors

  • "Error using * : Incorrect dimensions for matrix multiplication": Check that the column count of the first matrix equals the row count of the second (size(A,2) == size(B,1)).
  • "Warning: Matrix is singular to working precision": The determinant is zero (or near $10^{-16}$). The equations are linearly dependent; no unique solution exists.
  • Row vs Column vector mismatch in $A\mathbf{x} = \mathbf{b}$ : Ensure $\mathbf{b}$ is a column vector (semicolons between values, e.g. [5; 11]) when using A \ b.
  • Unexpected transpose output: Remember A' transposes the entire matrix. Check size(A') after transposing.
