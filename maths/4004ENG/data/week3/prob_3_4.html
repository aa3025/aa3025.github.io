Problem 4: Solving Systems of Equations Independent Consolidation

Learning Outcomes

  • Formulate systems of simultaneous linear equations in standard matrix form ($A\mathbf{x} = \mathbf{b}$).
  • Solve linear systems efficiently using MATLAB's backslash operator (\).
  • Utilize the linsolve() solver function for comparison.
  • Verify numerical solutions by reconstructing the constant vector ($A\mathbf{x} = \mathbf{b}$).

Description

One of the most powerful applications of matrices in engineering is solving large systems of simultaneous equations arising from circuit analysis and structural frameworks. In this exercise, you will master the industry-standard methods for solving linear systems in MATLAB.

Required Grader Variables

Variable Name Expected Type Dimension Description
A double $2 \times 2$ 2x2 coefficient matrix $[2, 3; 4, -1]$
b double $2 \times 1$ column 2x1 constant vector $[8; 2]$
x_sol_2x2 double $2 \times 1$ column Solution vector via A \ b
A3 double $3 \times 3$ 3x3 coefficient matrix
b3 double $3 \times 1$ column 3x1 constant vector $[6; -4; 27]$
x_sol_3x3 double $3 \times 1$ column 3x1 solution vector via linsolve()
b3_check double $3 \times 1$ column Reconstructed constant vector $A_3 \mathbf{x}$
x_sol_inv double $2 \times 1$ column Solution via matrix inversion $A^{-1}b$
Prediction Prompt: Why must $\mathbf{b}$ be entered as a column vector (using semicolons, e.g. [8; 2]) rather than a row vector when solving $A\mathbf{x} = \mathbf{b}$? (Because $A$ has 2 rows and 2 columns; matrix multiplication requires $A_{2 \times 2} \mathbf{x}_{2 \times 1} = \mathbf{b}_{2 \times 1}$).

Problem Tasks

Complete the following tasks in prob_3_4.m.

Part A — Solving a 2x2 System
Solve the simultaneous system: $$2x + 3y = 8$$ $$4x - y = 2$$

  1. Create the coefficient matrix A = [2, 3; 4, -1].
  2. Create the column constant vector b = [8; 2].
  3. Solve for x_sol_2x2 using the backslash operator (\).

Part B — Solving a 3x3 System
Solve the 3-variable system: $$x + y + z = 6$$ $$2y + 5z = -4$$ $$2x + 5y - z = 27$$ Create coefficient matrix A3 and column vector b3, then solve for x_sol_3x3 using linsolve().

Part C — Verification by Multiplication
Verify your 3x3 solution by calculating b3_check = A3 * x_sol_3x3. This should equal b3.

Part D — Matrix Inversion Method
Solve the 2x2 system from Part A again, this time using x_sol_inv = inv(A) * b.

Part E — Visualisation (Optional Extension)
Plot the two equations from Part A as lines on the same axes, then plot the intersection point from x_sol_2x2 to confirm the algebraic solution graphically.

Staged Hints

Hint 1: Concept Hint (Matrix Formulation $A\mathbf{x} = \mathbf{b}$)

Every linear system can be rewritten in matrix form:

$$\begin{bmatrix}a_{11} & a_{12}\\ a_{21} & a_{22}\end{bmatrix}\begin{bmatrix}x\\ y\end{bmatrix} = \begin{bmatrix}b_1\\ b_2\end{bmatrix}$$

In MATLAB, the backslash operator A \ b performs Gaussian elimination with partial pivoting, which is numerically faster and more stable than computing the explicit matrix inverse.

Hint 2: MATLAB Syntax Hint

Ensure b has semicolons between entries: b = [8; 2];. Solve using x_sol_2x2 = A \ b;. For Part B, call x_sol_3x3 = linsolve(A3, b3);.

Hint 3: Code Skeleton 
% Part A
A = [2, 3; 4, -1];
b = [8; 2];
x_sol_2x2 = A \ b;

% Part B
A3 = [1, 1, 1; 
      0, 2, 5; 
      2, 5, -1];
b3 = [6; -4; 27];
x_sol_3x3 = linsolve(A3, b3);

% Part C
b3_check = A3 * x_sol_3x3;

% Part D
x_sol_inv = inv(A) * b;

Self-Check & Expected Properties

  • x_sol_2x2 should equal [1; 2] (i.e. $x = 1, y = 2$).
  • x_sol_inv must match x_sol_2x2 exactly.
  • x_sol_3x3 should be [5; 3; -2] (i.e. $x = 5, y = 3, z = -2$).
  • norm(b3_check - b3) should be near zero ($< 10^{-14}$).

Engineering Reflection

In electrical nodal analysis, why is solving $G\mathbf{v} = \mathbf{i}$ with G \ i preferred over inv(G) * i when analyzing an integrated circuit with 10,000 nodes? (Answer: Gaussian elimination requires $O(n^3/3)$ operations versus $O(n^3)$ for inversion, consumes far less memory, and minimizes floating-point roundoff error.)
