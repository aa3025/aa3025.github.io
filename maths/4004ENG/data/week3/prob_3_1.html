Problem 1: Matrix Basics Live Core

Learning Outcomes

  • Define matrices in MATLAB using row and column syntax with semicolons.
  • Perform matrix transpose operations using the apostrophe (').
  • Execute basic matrix arithmetic (addition, subtraction, and scalar multiplication).
  • Verify dimension consistency for matrix addition.

Description

This exercise introduces the syntax for creating matrices of various dimensions in MATLAB and performing the fundamental operations required for engineering linear algebra.

Problem Tasks

Complete the following tasks in prob_3_1.m.

Part A — Create Matrices

  1. Create a $2\times3$ matrix A with rows $[1, 2, 3]$ and $[4, 5, 6]$.
  2. Create a $3\times2$ matrix B with rows $[7, 8]$, $[9, 10]$, and $[11, 12]$.

Part B — Matrix Transpose
Calculate the transpose of A and store it in A_trans using A_trans = A'.

Part C — Matrix Addition and Subtraction
Given $M = [1, 2; 3, 4]$ and $N = [5, 6; 7, 8]$:

  1. Store these as M and N.
  2. Calculate the sum S = M + N.
  3. Calculate the difference D = M - N.

Part D — Scalar Multiplication
Multiply M by a scalar factor of 10 and store the result in M_scaled.

Staged Hints

Hint 1: Concept Hint (Matrix Dimensions & Transpose)

A matrix of size $m \times n$ has $m$ rows and $n$ columns. The transpose operation swaps rows and columns such that $(A^T)_{ij} = A_{ji}$, resulting in an $n \times m$ matrix. Matrix addition requires identical dimensions ($m \times n$).

Hint 2: MATLAB Syntax Hint

Separate elements in the same row with spaces or commas, and separate rows with semicolons: A = [1, 2, 3; 4, 5, 6];. The transpose operator in MATLAB is the apostrophe '.

Hint 3: Code Skeleton 
% Part A
A = [1, 2, 3; 4, 5, 6];
B = [7, 8; 9, 10; 11, 12];

% Part B
A_trans = A';

% Part C
M = [1, 2; 3, 4];
N = [5, 6; 7, 8];
S = M + N;
D = M - N;

% Part D
M_scaled = 10 * M;

Self-Check & Expected Properties

  • size(A) is [2, 3]; size(A_trans) must be [3, 2].
  • S should equal [6, 8; 10, 12].
  • D should equal [-4, -4; -4, -4].
  • M_scaled should equal [10, 20; 30, 40].

Engineering Reflection

Why is transposing a matrix a common step in stress analysis when transforming local coordinate systems of a truss bar to global coordinates? (Answer: The coordinate transformation matrix is orthogonal, meaning its inverse equals its transpose: $T^{-1} = T^T$.)
