Problem 4: Cross Product and Orthogonality Independent Consolidation

Learning Outcomes

  • Compute the cross product of 3D vectors to find a mutually perpendicular vector.
  • Verify orthogonality using dot product checks.
  • Apply cross products to find normal vectors to engineering planes.
  • Calculate the area of a parallelogram defined by two vectors.

Description

Unlike the scalar dot product, the cross product produces a new vector perpendicular to both input vectors. This exercise focuses on calculating 3D normal vectors and computing geometric surface areas in CAD and structural engineering.

Required Grader Variables

Variable Name Expected Type Dimension Description / Units
a, b double $1 \times 3$ row Parallelogram edge vectors $[2, 3, -1]$ and $[-1, 4, 2]$ [m]
c_cross double $1 \times 3$ row Cross product $\mathbf{a} \times \mathbf{b}$ via cross()
verify_a, verify_b double $1 \times 1$ scalars Dot products $\mathbf{c} \cdot \mathbf{a}$ and $\mathbf{c} \cdot \mathbf{b}$ ($\approx 0$)
P1, P2, P3 double $1 \times 3$ rows Points on plane: $[0,0,0]$, $[3,0,0]$, $[0,4,2]$
v1, v2 double $1 \times 3$ rows Displacement vectors $P_2 - P_1$ and $P_3 - P_1$
n_normal double $1 \times 3$ row Plane surface normal $\mathbf{v}_1 \times \mathbf{v}_2$
area_parallelogram double $1 \times 1$ scalar Geometric area $\|\mathbf{a} \times \mathbf{b}\|$ [$\text{m}^2$]
Prediction Prompt: If vector $\mathbf{a}$ points along the positive $x$-axis $[1, 0, 0]$ and vector $\mathbf{b}$ points along the positive $y$-axis $[0, 1, 0]$, by the right-hand rule, along which axis will $\mathbf{a} \times \mathbf{b}$ point?

Problem Tasks

Complete the following tasks in prob_2_4.m.

Part A — Cross Product via cross()
Given vectors $\mathbf{a} = [2, 3, -1]$ m and $\mathbf{b} = [-1, 4, 2]$ m representing edges of a parallelogram, store them as a and b and calculate c_cross $= \mathbf{a} \times \mathbf{b}$ using the cross() function.

Part B — Verify Orthogonality
Confirm that c_cross is perpendicular to both a and b by calculating verify_a = dot(c_cross, a) and verify_b = dot(c_cross, b). Both results should be zero within floating-point tolerance.

Part C — Normal Vector to a Plane
Given three points on a structural plane: $P_1 = [0,0,0]$, $P_2 = [3,0,0]$, $P_3 = [0,4,2]$:

  1. Store the points as P1, P2, P3.
  2. Create vector v1 from $P_1$ to $P_2$ ($P_2 - P_1$), and vector v2 from $P_1$ to $P_3$ ($P_3 - P_1$).
  3. Calculate the plane normal vector n_normal $= \mathbf{v_1} \times \mathbf{v_2}$.

Part D — Area of a Parallelogram
Calculate area_parallelogram, the area of the parallelogram spanned by $\mathbf{a}$ and $\mathbf{b}$, using $\text{Area} = |\mathbf{a} \times \mathbf{b}|$ (i.e. the norm() of your Part A cross product).

Part E — Visualisation (Optional Extension)
Create a 3D vector plot (e.g. using quiver3) showing a, b, and c_cross emanating from the origin with axis equal.

Staged Hints

Hint 1: Concept Hint (Cross Product Properties)

The vector cross product is defined only in 3D space. It produces a vector perpendicular to the plane containing $\mathbf{a}$ and $\mathbf{b}$:

$$\mathbf{a} \times \mathbf{b} = [a_y b_z - a_z b_y, \; a_z b_x - a_x b_z, \; a_x b_y - a_y b_x]$$

The magnitude $\|\mathbf{a} \times \mathbf{b}\|$ exactly equals the area of the parallelogram formed by the two vectors.

Hint 2: MATLAB Syntax Hint

Use cross(a, b). For points on a plane, form directional displacement vectors by subtracting points: v1 = P2 - P1;. Find area with norm(c_cross).

Hint 3: Code Skeleton 
% Part A
a = [2, 3, -1];
b = [-1, 4, 2];
c_cross = cross(a, b);

% Part B
verify_a = dot(c_cross, a);
verify_b = dot(c_cross, b);

% Part C
P1 = [0, 0, 0];
P2 = [3, 0, 0];
P3 = [0, 4, 2];
v1 = P2 - P1;
v2 = P3 - P1;
n_normal = cross(v1, v2);

% Part D
area_parallelogram = norm(c_cross);

Self-Check & Expected Properties

  • c_cross should be $[3\times 2 - (-1)\times 4, \; (-1)\times(-1) - 2\times 2, \; 2\times 4 - 3\times(-1)] = [10, -3, 11]$.
  • verify_a and verify_b must be $0.0$ (or $< 10^{-14}$).
  • n_normal should point purely along the $y$ and $z$ axes: $[0, -6, 12]$.
  • area_parallelogram is $\sqrt{100 + 9 + 121} = \sqrt{230} \approx 15.166$.

Engineering Reflection

In 3D CAD modeling and finite element stress analysis, why does every planar polygon require a surface normal vector $\mathbf{\hat{n}}$? (Answer: To define which side is the outer surface for pressure load application, fluid drag, and optical ray tracing.)
