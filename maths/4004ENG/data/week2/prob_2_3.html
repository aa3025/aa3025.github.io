Problem 3: Dot Product and Angle Between Vectors Live Core

Learning Outcomes

  • Calculate the scalar (dot) product using MATLAB's built-in dot() function.
  • Implement manual dot product calculations for 3D vectors.
  • Determine the angle between two spatial vectors using the dot product formula.
  • Convert angular measurements between radians and degrees using rad2deg().

Description

The dot product is a key tool for finding the directional alignment between two vectors. You will use it to calculate projections and determine the exact angle between force and velocity vectors.

Required Grader Variables

Prediction Prompt: For $\mathbf{v}_1 = [4, -2, 3]$ and $\mathbf{v}_2 = [-1, 5, 2]$, estimate the sign of $\mathbf{v}_1 \cdot \mathbf{v}_2$: $(4)(-1) + (-2)(5) + (3)(2) = -4 - 10 + 6 = -8$. Since the dot product is negative, will the angle $\theta$ be acute ($<90^\circ$) or obtuse ($>90^\circ$)?

Problem Tasks

Complete the following tasks in prob_2_3.m.

Part A — Dot Product via dot()
Given force vectors $\mathbf{F_1} = [10, 5, -2]$ N and $\mathbf{F_2} = [3, -4, 6]$ N, store them as F1 and F2 and calculate their dot product dot_F1F2 using the dot() function.

Part B — Manual Dot Product
Given position vectors $\mathbf{A} = [2, -3, 1]$ m and $\mathbf{B} = [-1, 4, 5]$ m, store them as A and B and calculate dot_AB_manual manually using: $$\mathbf{A}\cdot\mathbf{B} = A_xB_x + A_yB_y + A_zB_z$$

Part C — Angle Between Two Vectors
Given velocity vectors $\mathbf{v_1} = [4, -2, 3]$ m/s and $\mathbf{v_2} = [-1, 5, 2]$ m/s, store them as v1 and v2, then:

  1. Calculate the dot product dot_v1v2.
  2. Calculate the magnitudes mag_v1 and mag_v2.
  3. Use $\cos\theta = \dfrac{\mathbf{v_1}\cdot\mathbf{v_2}}{|\mathbf{v_1}||\mathbf{v_2}|}$ and acos() to find theta_rad.

Part D — Convert to Degrees
Convert theta_rad to theta_deg using rad2deg() (or by multiplying by $180/\pi$).

Part E — Visualisation (Optional Extension)
Plot v1 and v2 as vectors on the same axes using quiver or plot3 to visually observe the obtuse angle between them.

Staged Hints

Hint 1: Concept Hint (Angle Between Vectors)

From the geometric definition of the scalar product $\mathbf{a} \cdot \mathbf{b} = \|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$, the angle is:

$$\theta = \arccos\left(\frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{a}\|\|\mathbf{b}\|}\right)$$

If $\mathbf{a}\cdot\mathbf{b} > 0$, $\theta$ is acute. If $\mathbf{a}\cdot\mathbf{b} = 0$, $\theta = 90^\circ$ (perpendicular). If $\mathbf{a}\cdot\mathbf{b} < 0$, $\theta$ is obtuse.

Hint 2: MATLAB Syntax Hint

Use dot(v1, v2) for the numerator and norm(v1) * norm(v2) for the denominator. Wrap the quotient in acos(...). MATLAB returns radians; use rad2deg(...) to convert to degrees.

Hint 3: Code Skeleton 
% Part A
F1 = [10, 5, -2];
F2 = [3, -4, 6];
dot_F1F2 = dot(F1, F2);

% Part B
A = [2, -3, 1];
B = [-1, 4, 5];
dot_AB_manual = A(1)*B(1) + A(2)*B(2) + A(3)*B(3);

% Part C
v1 = [4, -2, 3];
v2 = [-1, 5, 2];
dot_v1v2 = dot(v1, v2);
mag_v1 = norm(v1);
mag_v2 = norm(v2);
theta_rad = acos(dot_v1v2 / (mag_v1 * mag_v2));

% Part D
theta_deg = rad2deg(theta_rad);

Self-Check & Expected Properties

  • dot_F1F2 should be $30 - 20 - 12 = -2$.
  • dot_AB_manual should be $-2 - 12 + 5 = -9$.
  • dot_v1v2 is negative ($-8$), so theta_deg must be greater than $90^\circ$ (approx. $106.1^\circ$).

Engineering Reflection

If two aircraft are tracking along velocity vectors $\mathbf{v}_1$ and $\mathbf{v}_2$ and radar telemetry indicates $\mathbf{v}_1 \cdot \mathbf{v}_2 = 0$, what does this reveal about their flight paths relative to one another? (Answer: Their flight paths are mutually perpendicular.)
