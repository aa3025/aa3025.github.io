Problem 2: Magnitude and Unit Vectors Live Core

Learning Outcomes

  • Calculate the magnitude (length) of a vector using the built-in norm() function.
  • Implement manual magnitude calculations using the 3D Pythagorean theorem.
  • Create normalized directional unit vectors to represent line of action.
  • Verify vector properties using numerical floating-point tolerances.

Description

Calculating the size of a vector and isolating its pure direction is critical for structural and force analysis. In this exercise, you will calculate Euclidean magnitudes and normalize vectors into unit vectors.

Required Grader Variables

Variable Name Expected Type Dimension Description / Units
r double $1 \times 3$ row Position vector $[3, 4, 12]$ [m]
mag_r double $1 \times 1$ scalar Norm of $\mathbf{r}$ via norm(r) [m]
F double $1 \times 3$ row Force vector $[6, -8, 0]$ [N]
mag_F_manual double $1 \times 1$ scalar Pythagorean magnitude $\sqrt{F_x^2 + F_y^2 + F_z^2}$ [N]
d double $1 \times 3$ row Displacement vector $[2, -3, 6]$ [m]
u_hat_d double $1 \times 3$ row Normalized unit vector $\mathbf{d} / \|\mathbf{d}\|$ (dimensionless)
mag_unit_d double $1 \times 1$ scalar Norm of unit vector $\approx 1.0$
Prediction Prompt: For $\mathbf{r} = [3, 4, 12]$, predict $\|\mathbf{r}\|$ mentally: $\sqrt{3^2 + 4^2} = 5$, then $\sqrt{5^2 + 12^2} = 13$. Can a vector magnitude ever be negative?

Problem Tasks

Complete the following tasks in prob_2_2.m.

Part A — Magnitude via norm()
Given position vector $\mathbf{r} = [3, 4, 12]$ m, store it as r and calculate its magnitude mag_r using the built-in norm() function.

Part B — Manual Magnitude Calculation
Given force vector $\mathbf{F} = [6, -8, 0]$ N, store it as F and calculate its magnitude mag_F_manual manually using: $$|\mathbf{F}| = \sqrt{F_x^2 + F_y^2 + F_z^2}$$

Part C — Create a Unit Vector
Given displacement vector $\mathbf{d} = [2, -3, 6]$, store it as d and calculate the unit vector u_hat_d in the direction of d: $$\hat{\mathbf{u}}_d = \frac{\mathbf{d}}{|\mathbf{d}|}$$

Part D — Verify Your Unit Vector
Calculate the magnitude mag_unit_d of u_hat_d using norm(). Due to standard IEEE floating-point rounding, verify that it equals $1$ within numerical tolerance (e.g. abs(mag_unit_d - 1) < 1e-12).

Staged Hints

Hint 1: Concept Hint (Unit Vectors)

A unit vector points in the identical direction as the original vector but has a scaled length of exactly 1. It is computed by dividing every component by the vector's Euclidean magnitude: $\mathbf{\hat{u}} = \mathbf{d} / \|\mathbf{d}\|$.

Hint 2: MATLAB Syntax Hint

Use norm(d) for magnitude. To compute components manually, index with parentheses: F(1), F(2), F(3). Use sqrt(...) for square roots.

Hint 3: Code Skeleton 
% Part A
r = [3, 4, 12];
mag_r = norm(____);

% Part B
F = [6, -8, 0];
mag_F_manual = sqrt(F(1)^2 + F(2)^2 + F(3)^2);

% Part C
d = [2, -3, 6];
u_hat_d = d / norm(____);

% Part D
mag_unit_d = norm(u_hat_d);

Self-Check & Expected Properties

  • mag_r should equal exactly 13.
  • mag_F_manual should equal exactly 10.
  • norm(d) is $\sqrt{4 + 9 + 36} = 7$, so u_hat_d is approximately [0.2857, -0.4286, 0.8571].
  • abs(mag_unit_d - 1.0) should be zero within machine epsilon ($< 10^{-14}$).

Engineering Reflection

Why do structural engineers decompose cable forces into a scalar tension magnitude times a directional unit vector $\mathbf{F} = T \mathbf{\hat{u}}$? (Answer: It separates the variable load intensity $T$ from the fixed geometric orientation of the cable $\mathbf{\hat{u}}$.)
