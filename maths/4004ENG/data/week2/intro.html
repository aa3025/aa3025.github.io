Week 2: Vectors & Geometric Applications

Why This Matters in Engineering

Vectors are the foundational mathematical language of the physical world. In mechanical, civil, and aerospace engineering, quantities such as forces on bridge trusses, aircraft velocities in crosswinds, fluid velocity fields, and robotic manipulator links have both a magnitude and a direction.

In this module, you will master vector operations in MATLAB — computing magnitudes, normalizing vectors into directional unit vectors, calculating dot products to find angles and mechanical work, and taking cross products to compute 3D surface normals and moments. MATLAB's vectorized syntax lets you perform these calculations simultaneously across thousands of data points without slow scalar loops.

Quick Formative Checks

Readiness Check 1: Unit Vector Property

Question: If vector $\mathbf{v} = [3, 4]$, what is its magnitude, and what is its unit vector $\mathbf{\hat{v}}$?

Answer: Magnitude is $\|\mathbf{v}\| = \sqrt{3^2 + 4^2} = 5$. The unit vector is $\mathbf{\hat{v}} = [3/5, 4/5] = [0.6, 0.8]$. Its magnitude is $\|\mathbf{\hat{v}}\| = \sqrt{0.6^2 + 0.8^2} = 1.0$.

Readiness Check 2: Dot Product and Orthogonality

Question: What does dot([1, 0], [0, 5]) == 0 tell you about the two vectors?

Answer: Since $\mathbf{a} \cdot \mathbf{b} = \|\mathbf{a}\| \|\mathbf{b}\| \cos\theta = 0$ and neither vector has zero magnitude, $\cos\theta = 0$, meaning the angle is $\theta = 90^\circ$. The vectors are orthogonal (perpendicular).

Quick Reference: Vector Mathematics

Operation Mathematical Formula MATLAB Command Notes / Grader Gotcha
Vector Definition $\mathbf{v} = [v_1, v_2, v_3]$ v = [1, 2, 3]; Row vector (use commas/spaces, not semicolons)
Magnitude (Length) $\|\mathbf{v}\| = \sqrt{\sum v_i^2}$ mag_v = norm(v); Returns a non-negative scalar
Unit Vector $\mathbf{\hat{v}} = \frac{\mathbf{v}}{\|\mathbf{v}\|}$ u_hat = v / norm(v); Magnitude is $1.0$ (verify with abs(norm(u_hat)-1) < 1e-12)
Dot Product $\mathbf{a} \cdot \mathbf{b} = \sum a_i b_i$ d = dot(a, b); Scalar result; 0 indicates perpendicular vectors
Angle Between $\theta = \arccos\left(\frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{a}\|\|\mathbf{b}\|}\right)$ th = acos(dot(a,b)/(norm(a)*norm(b))); acos() returns radians; use rad2deg() for degrees
Cross Product $\mathbf{a} \times \mathbf{b}$ c = cross(a, b); Strictly for 3D vectors; result is orthogonal to both
Work Done $W = \mathbf{F} \cdot \mathbf{d}$ W = dot(F, d); Scalar energy in Joules ($1\text{ N}\cdot\text{m} = 1\text{ J}$)

Worked Examples

Example 1: Magnitude and Normalized Unit Vector

% Define 3D displacement vector
d = [2, -3, 6];

% Compute Euclidean norm
mag_d = norm(d);            % sqrt(4 + 9 + 36) = sqrt(49) = 7

% Directional unit vector
u_hat = d / mag_d;          % [2/7, -3/7, 6/7]

% Sanity check: unit vector magnitude must be 1 (within floating point tolerance)
is_valid_unit = abs(norm(u_hat) - 1.0) < 1e-12;  % returns true (1)

Example 2: Angle Between Force Vectors

F1 = [10, 0, 5];
F2 = [0, 8, 2];

% Dot product
dp = dot(F1, F2);           % 10*0 + 0*8 + 5*2 = 10

% Angle calculation
cos_theta = dp / (norm(F1) * norm(F2));
theta_rad = acos(cos_theta);
theta_deg = rad2deg(theta_rad);  % Angle in degrees

Example 3: 3D Surface Normal via Cross Product

% Two vectors lying on a structural plate
v1 = [1, 0, 0];
v2 = [0, 1, 0];

% Normal vector perpendicular to the plate surface
n = cross(v1, v2);          % [0, 0, 1] (unit vector in +z direction)

% Verify orthogonality: dot products with original vectors must be zero
check1 = dot(n, v1);        % 0
check2 = dot(n, v2);        % 0

Remote Lab Help: Common Errors in Vectors

  • "Matrix dimensions must agree": You tried to add or subtract vectors of different lengths (e.g. adding a 2D vector [1, 2] to a 3D vector [1, 2, 3]).
  • "Inner matrix dimensions must agree" on multiplication: Using a * b for two row vectors. To multiply element-by-element use a .* b; to compute scalar dot product use dot(a, b).
  • Cross product error: cross(a, b) requires both vectors to have exactly 3 components. For 2D vectors in the $xy$-plane, pad with zero: [x, y, 0].
  • Angle seems huge or tiny: MATLAB's acos() returns radians. Multiply by 180/pi or use rad2deg().
