Week 5: Integration & Applications

Why This Matters in Engineering

Integration is the mathematical engine for calculating accumulated physical quantities over continuous space and time. In mechanical and civil engineering, integrating distributed loads across a beam yields total shear and moment; integrating non-constant pressure distributions across an aerofoil gives total aerodynamic lift; and integrating force over a displacement path determines the mechanical work done ($W = \int F(x)\,dx$). In fluid dynamics and electrical engineering, integration calculates total volumetric flow from varying flow rates and total stored electrical charge from current waveforms ($Q = \int i(t)\,dt$).

In this module, you will learn when to use symbolic integration (int) to obtain exact closed-form algebraic formulas, and when to use numerical integration (integral) for experimental datasets or non-integrable functions.

Quick Formative Checks

Readiness Check 1: Indefinite Integration & the Constant of Integration

Question: Why does MATLAB's int(cos(x), x) return sin(x) rather than sin(x) + C?

Answer: MATLAB's symbolic engine sets the arbitrary constant of integration $C = 0$ by convention. When applying indefinite integrals to engineering boundary conditions, you must add and solve for the constant $C$ manually.

Readiness Check 2: Choosing Symbolic vs Numerical Integration

Question: When should you choose integral() over int()?

Answer: Use integral() when the function has no closed-form antiderivative (e.g. Gaussian $e^{-x^2}$), when integrating over semi-infinite numerical domains, or when evaluating experimental/sampled data. Always use element-wise operators (.*, ./, .^) inside the anonymous function handle passed to integral().

Quick Reference: Integration in MATLAB

Symbolic vs Numerical Decision Guide

Feature Symbolic: int() Numerical: integral()
Input Type Symbolic expression (syms x; f = ...) Anonymous function handle (f = @(x) ...)
Syntax int(f, x, a, b) integral(f, a, b)
Result Exact mathematical formula or exact fraction IEEE double floating-point scalar
Best Used For Deriving analytical equations, antiderivatives Complex integrands with no known antiderivative
Element-Wise Requirement Not strictly required (symbolic algebra) Strictly required (.*, ./, .^)

Worked Examples

Example 1: Indefinite and Definite Symbolic Integration

syms x
f = 3*x^2 + 2*x + 1;

% Indefinite integral (returns x^3 + x^2 + x)
F_indef = int(f, x);

% Definite integral from x = 1 to x = 4
I_def = int(f, x, 1, 4);
I_num = double(I_def);   % Returns: 78

Example 2: Integration by Parts

syms x
g = x * exp(-2*x);

% int() handles integration by parts automatically
G = int(g, x);           % Returns: -exp(-2*x)*(2*x + 1)/4

Example 3: Numerical Integration of a Non-Elementary Function

% Error function integrand: f(x) = exp(-x^2)
% MUST use element-wise .^ in function handle!
f_anon = @(x) exp(-x.^2);

% Integrate from 0 to Inf
I_gaussian = integral(f_anon, 0, Inf);  % Returns: 0.8862 (sqrt(pi)/2)

Example 4: Area Between Two Curves

syms x
y_top = 2*x;
y_bottom = x^2;

% Find intersection points analytically
pts = solve(y_top == y_bottom, x);   % [0; 2]
x_a = min(double(pts));
x_b = max(double(pts));

% Area is integral of (top - bottom)
A_sym = int(y_top - y_bottom, x, x_a, x_b);
A_val = double(A_sym);               % Returns: 1.3333 (4/3)
Prediction Check: Why must you subtract $(y_{\text{top}} - y_{\text{bottom}})$? If you reversed them, the integral would yield $-1.3333$. Physical area is always non-negative!

Example 5: Work from Variable Force

syms x
% Force varies inversely with position: F(x) = 150 / (2 + x)
F = 150 / (2 + x);

% Work done from x = 0 m to x = 10 m
W_sym = int(F, x, 0, 10);
W_joules = double(W_sym);            % Returns: 268.7 Joules

Remote Lab Help: Integration Pitfalls

  • "Error using integral / Operands must be the same size": You forgot element-wise operators in your function handle. Change @(x) x*sin(x) to @(x) x.*sin(x) and x^2 to x.^2.
  • Indefinite vs Definite output: int(f, x) returns a symbolic expression (formula). int(f, x, a, b) returns a single scalar number.
  • Comparing Symbolic vs Numerical results: Compare using an explicit tolerance: 
    is_match = abs(double(val_sym) - val_num) < 1e-6;
  • Negative area result: Check which function is upper on the interval. If curves cross, you must split the integral at the intersection points!
