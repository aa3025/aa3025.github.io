Problem 1: Basic Symbolic Integration Live Core

Learning Outcomes

  • Calculate analytical antiderivatives (indefinite integrals) for polynomial, trigonometric, and exponential functions.
  • Compute definite integrals over specific limits using int().
  • Convert symbolic definite integrals into IEEE double numeric format for engineering reporting.
  • Understand why MATLAB's symbolic integrator omits the constant of integration ($+ C$).

Description

Integration is a core computational tool for determining accumulated quantities, such as calculating displacement from velocity or stored energy from power. This exercise introduces MATLAB's symbolic solver for analytical indefinite and definite integrals.

Problem Tasks

Complete the following tasks in prob_5_1.m.

Part A — Indefinite Integrals
Define symbolic variable x, then find the indefinite integral (antiderivative) of each of the following, storing the functions as f1, f2, f3 and their integrals as F1, F2, F3:

  1. $f_1 = 5x^3 - 2x + 4$
  2. $f_2 = \sin(3x)$
  3. $f_3 = e^{2x}$ (use exp(2*x))

Part B — Definite Integral
Calculate the definite integral val_definite of $g(x) = x^2+1$ from $x=0$ to $x=3$ using int(g, x, 0, 3).

Part C — Numerical Conversion
Convert the symbolic result val_definite into a standard MATLAB numeric value result_numeric using double().

Staged Hints

Hint 1: Concept Hint (Fundamental Theorem of Calculus)

The antiderivative of $x^n$ is $\frac{x^{n+1}}{n+1}$ (for $n \neq -1$). For trigonometric terms, $\int \sin(kx)\,dx = -\frac{1}{k}\cos(kx)$. For exponential terms, $\int e^{kx}\,dx = \frac{1}{k}e^{kx}$. Definite integration evaluates the antiderivative across limits: $\int_a^b f(x)dx = F(b) - F(a)$.

Hint 2: MATLAB Syntax Hint

Declare syms x. For indefinite integrals, use int(f, x). For definite integrals over $[a, b]$, supply limits as additional arguments: int(f, x, a, b). Use double() to convert symbolic numbers to standard floating-point format.

Hint 3: Code Skeleton 
syms x

% Part A
f1 = 5*x^3 - 2*x + 4;
F1 = int(f1, x);

f2 = sin(3*x);
F2 = int(f2, x);

f3 = exp(2*x);
F3 = int(f3, x);

% Part B
g = x^2 + 1;
val_definite = int(g, x, 0, 3);

% Part C
result_numeric = double(val_definite);

Self-Check & Expected Properties

  • F1 must be (5*x^4)/4 - x^2 + 4*x.
  • F2 must be -cos(3*x)/3.
  • F3 must be exp(2*x)/2.
  • result_numeric must equal exactly 12.0.

Engineering Reflection

If an accelerometer records a vehicle's acceleration $a(t) = 3t^2 - 4$, why does integrating to find velocity $v(t) = \int a(t)\,dt$ require adding an initial velocity condition $v_0$? (Answer: An indefinite integral yields an entire family of curves; the initial velocity $v(0) = v_0$ provides the specific boundary constant $C$.)
