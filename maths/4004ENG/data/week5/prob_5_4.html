Problem 4: Area Under and Between Curves Independent Consolidation

Learning Outcomes

  • Calculate geometric area under a continuous curve using definite symbolic integration.
  • Determine the analytical intersection points of intersecting curves using solve().
  • Compute the enclosed area between two curves by integrating their vertical difference.
  • Handle total absolute area for functions that cross below the horizontal $x$-axis.

Description

In structural beam sections, aerodynamic aerofoils, and hydraulic channels, calculating cross-sectional area requires integrating between bounded functions. In this exercise, you will solve for boundary limits and calculate net and absolute geometric areas.

Required Grader Variables

Variable Name Expected Type Dimension Description
y1 sym $1 \times 1$ sym Curve expression $x\sin(x)$
area_y1 sym / double $1 \times 1$ scalar Area under $y_1$ from $x=0$ to $\pi$
y_top, y_bottom sym $1 \times 1$ syms Upper curve $x$ and lower curve $x^2$ on $[0, 1]$
intersection_pts sym / double $2 \times 1$ column Roots $[0; 1]$ via solve(y_top == y_bottom, x)
area_between sym / double $1 \times 1$ scalar Enclosed area $\int_0^1 (x - x^2)dx$
area_total sym / double $1 \times 1$ scalar Absolute geometric area of $\sin(x)$ over $[0, 2\pi]$ ($= 4$)
Prediction Prompt: A student calculates $\int_0^{2\pi} \sin(x)\,dx = [-\cos(x)]_0^{2\pi} = -1 - (-1) = 0$. Does this mean the geometric area enclosed between $y=\sin(x)$ and the $x$-axis is zero? (No! The positive lobe $[0, \pi]$ has area $2$ and the negative lobe $[\pi, 2\pi]$ has signed integral $-2$, canceling out. True geometric area is $|2| + |-2| = 4$).

Problem Tasks

Complete the following tasks in prob_5_4.m. Declare symbolic variable x.

Part A — Area Under a Single Curve
Find the area area_y1 under $y_1 = x\sin(x)$ from $x=0$ to $x=\pi$. Store the function as y1 and integrate with int(y1, x, 0, pi).

Part B — Area Between Two Curves
Find the area bounded between $y = x$ (y_top) and $y = x^2$ (y_bottom):

  1. Find the intersection points using solve(y_top == y_bottom, x), storing them in intersection_pts.
  2. Integrate the difference (y_top - y_bottom) between the lower and upper intersection limits to calculate area_between.

Part C — Absolute Area
Calculate the total absolute geometric area area_total under $y = \sin(x)$ from $0$ to $2\pi$ by splitting the integral at the zero crossing ($x = \pi$): $\int_0^\pi \sin(x)dx + \int_\pi^{2\pi} (-\sin(x))dx$, or using int(abs(sin(x)), x, 0, 2*pi).

Part D — Visualisation (Optional Extension)
Plot $y = x$ and $y = x^2$ on $[0, 1.2]$ and shade the bounded region between $0$ and $1$.

Staged Hints

Hint 1: Concept Hint (Area Between Curves)

If $f(x) \ge g(x)$ on $[a, b]$, the enclosed area between the curves is given by $\int_a^b [f(x) - g(x)]\,dx$. On the interval $[0, 1]$, $x \ge x^2$, so $y_{\text{top}} = x$ and $y_{\text{bottom}} = x^2$. For functions that cross the axis, geometric area requires taking the absolute value of negative regions.

Hint 2: MATLAB Syntax Hint

Solve intersections with intersection_pts = solve(y_top == y_bottom, x);. Integrate with area_between = int(y_top - y_bottom, x, intersection_pts(1), intersection_pts(2));.

Hint 3: Code Skeleton 
syms x

% Part A
y1 = x * sin(x);
area_y1 = int(y1, x, 0, pi);

% Part B
y_top = x;
y_bottom = x^2;
intersection_pts = solve(y_top == y_bottom, x);
area_between = int(y_top - y_bottom, x, intersection_pts(1), intersection_pts(2));

% Part C
area_total = int(sin(x), x, 0, pi) + int(-sin(x), x, pi, 2*pi);

Self-Check & Expected Properties

  • double(area_y1) should equal $\pi \approx 3.1416$.
  • double(intersection_pts) should be [0; 1].
  • double(area_between) is $[\frac{x^2}{2} - \frac{x^3}{3}]_0^1 = \frac{1}{2} - \frac{1}{3} = \frac{1}{6} \approx 0.1667$.
  • double(area_total) must equal exactly $4.0$.

Engineering Reflection

When calculating the cross-sectional area and moment of inertia ($I_x = \int y^2 dA$) of a hollow structural I-beam, why is integrating the difference between bounding upper and lower flanges necessary? (Answer: It allows decomposing complex extruded cross-sections into simple bounded geometric integrals.)
