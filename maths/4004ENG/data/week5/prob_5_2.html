Learning Outcomes

  • Solve complex integrals involving analytical substitution ($u$-substitution).
  • Apply integration by parts ($\int u\,dv = uv - \int v\,du$) symbolically.
  • Handle rational functions using partial fraction decomposition.
  • Evaluate definite integrals of composite analytical functions.

Description

Many real-world engineering integrals involve composite functions requiring substitution, parts, or partial fractions. In this problem, you will use MATLAB's symbolic engine to solve advanced analytical integrals and verify pen-and-paper solutions.

Prediction Prompt: For $\int 2x e^{x^2}\,dx$, substitute $u = x^2 \implies du = 2x\,dx$. The integral reduces to $\int e^u du = e^u = e^{x^2}$. Evaluating from $x=0$ to $1$ gives $e^1 - e^0 = e - 1 \approx 1.7183$.

Problem Tasks

Complete the following tasks in prob_5_2.m. Declare symbolic variable x.

Part A — Integration by Substitution
Find the indefinite integral of $f(x) = 2x\,e^{x^2}$. Store the function as f_sub and the result as F_sub.

Part B — Integration by Parts
Find the indefinite integral of $g(x) = x\sin(x)$. Store the function as g_parts and the result as G_parts.

Part C — Partial Fractions
Find the indefinite integral of $h(x) = \dfrac{1}{x^2-1}$. Store the function as h_rational and the result as H_rational.

Part D — Definite Application
Calculate result_definite, the definite integral of f_sub from $x=0$ to $x=1$.

Staged Hints

Hint 1: Concept Hint (Advanced Integration Rules)
  • Substitution: Identifies an inner function $u(x)$ whose derivative $u'(x)$ appears in the integrand: $\int f(u(x))u'(x)dx = \int f(u)du$.
  • Integration by Parts: Derived from the product rule: $\int u\,dv = uv - \int v\,du$. For $\int x\sin(x)dx$, set $u=x$ and $dv = \sin(x)dx$.
  • Partial Fractions: Decomposes $\frac{1}{x^2-1} = \frac{1}{(x-1)(x+1)} = \frac{1/2}{x-1} - \frac{1/2}{x+1}$, integrating into logarithms.
Hint 2: MATLAB Syntax Hint

MATLAB's int() function automatically applies substitution, parts, and partial fraction expansions internally. Call int(f_sub, x), int(g_parts, x), and int(h_rational, x).

Hint 3: Code Skeleton 
syms x

% Part A
f_sub = 2*x * exp(x^2);
F_sub = int(f_sub, x);

% Part B
g_parts = x * sin(x);
G_parts = int(g_parts, x);

% Part C
h_rational = 1 / (x^2 - 1);
H_rational = int(h_rational, x);

% Part D
result_definite = int(f_sub, x, 0, 1);

Self-Check & Expected Properties

  • F_sub must equal exp(x^2).
  • G_parts must equal sin(x) - x*cos(x).
  • H_rational involves logarithms: $-\text{atanh}(x)$ or $\frac{1}{2}\log(x-1) - \frac{1}{2}\log(x+1)$.
  • double(result_definite) should equal $e - 1 \approx 1.7183$.

Engineering Reflection

When solving transient heat transfer or signal filtering equations containing terms like $t e^{-at}$, why does integration by parts arise naturally? (Answer: The differential equations governing linear systems produce product convolutions of polynomial inputs and exponential impulse responses.)
