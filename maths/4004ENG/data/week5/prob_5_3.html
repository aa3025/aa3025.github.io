Problem 3: Numerical Integration Live Core

Learning Outcomes

  • Construct vectorized anonymous functions using @(x) syntax with element-wise operators.
  • Perform numerical quadrature using MATLAB's global adaptive solver integral().
  • Evaluate improper integrals with semi-infinite upper integration limits (Inf).
  • Compare analytical symbolic results with numerical results within machine tolerance.

Description

When physical integrand expressions cannot be solved analytically in closed form, numerical integration provides high-accuracy approximations using adaptive quadrature. In this problem, you will use integral() and compare its efficiency against symbolic methods.

Prediction Prompt: How does MATLAB's integral() handle an infinite limit Inf? Rather than stepping infinitely, it applies mathematical coordinate transformations (e.g. $x = t / (1-t)$) that map $[0, \infty)$ onto a compact interval $[0, 1)$.

Problem Tasks

Complete the following tasks in prob_5_3.m.

Part A — Define an Anonymous Function
Create a function handle f_num for $f(x) = e^{-x^2}\cos(x)$, using element-wise operators (.^, .*).

Part B — Numerical Integration
Calculate result_0_2, the definite integral of f_num from $x=0$ to $x=2$, using the integral() function.

Part C — Improper Integral
Use integral() to find result_inf, the area under f_num from $x=0$ to $x=\infty$ (use Inf for the upper limit).

Part D — Compare with the Symbolic Method
Define x as symbolic, rebuild the same function as f_sym, and calculate the same integral from $x=0$ to $2$ symbolically as result_sym. Calculate diff_val, the difference between double(result_sym) and result_0_2.

Staged Hints

Hint 1: Concept Hint (Numerical Quadrature)

Adaptive quadrature estimates $\int_a^b f(x)dx$ by sampling the integrand at dynamically spaced points, concentrating evaluation nodes where the function exhibits sharp curvature or rapid oscillations.

Hint 2: MATLAB Syntax Hint

Always include dots: @(x) exp(-x.^2) .* cos(x). Call integral(f_num, 0, 2) and integral(f_num, 0, Inf). Compute difference with abs(double(result_sym) - result_0_2).

Hint 3: Code Skeleton 
% Part A
f_num = @(x) exp(-x.^2) .* cos(x);

% Part B
result_0_2 = integral(f_num, 0, 2);

% Part C
result_inf = integral(f_num, 0, Inf);

% Part D
syms x
f_sym = exp(-x^2) * cos(x);
result_sym = int(f_sym, x, 0, 2);
diff_val = abs(double(result_sym) - result_0_2);

Self-Check & Expected Properties

  • result_0_2 should be approximately 0.6946.
  • result_inf should be approximately 0.6865.
  • diff_val must be virtually zero ($< 10^{-10}$), confirming that both numerical quadrature and symbolic integration converge to the same truth.

Engineering Reflection

Why is numerical integration preferred when processing sampled aerodynamic pressure measurements from a wind tunnel sensor grid? (Answer: Experimental data exists only at discrete measurement points; there is no analytical mathematical formula to differentiate or integrate symbolically.)
