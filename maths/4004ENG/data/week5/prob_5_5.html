Problem 5: Engineering Application - Work Done Optional Stretch

Learning Outcomes

  • Model mechanical work as the integral of non-constant force with respect to distance: $W = \int_{x_1}^{x_2} F(x)\,dx$.
  • Apply both symbolic (int) and numerical (integral) calculus to solve real-world energy problems.
  • Convert analytical energy equations into numerical quantities with engineering units (Joules).
  • Evaluate energy dissipation and spring potential storage.

Description

In physics and mechanical engineering, work is defined as an integral whenever applied forces vary continuously with position. In this engineering application, you will compute the mechanical energy required to compress an elastic spring, drive a hydraulic piston against resistance, and overcome non-linear oscillating external forces.

Prediction Prompt: For the linear spring $F(x) = kx$ with $k=500\text{ N/m}$, integrate by hand: $\int_0^{0.2} 500x\,dx = [250 x^2]_0^{0.2} = 250(0.04) = 10\text{ J}$. Does energy increase linearly or quadratically with displacement?

Problem Tasks

Complete the following tasks in prob_5_5.m. Recall that mechanical work is $W = \displaystyle\int_{x_1}^{x_2} F(x)\,dx$.

Part A — Symbolic Calculation (Spring)
A linear spring exerts restoring force $F(x) = kx$ with stiffness $k = 500$ N/m. Calculate work_spring, the work done compressing the spring from $x = 0$ to $x = 0.2$ m using symbolic integration.

Part B — Variable Force (Piston)
A hydraulic piston moves against a fluid resistance force $F(x) = \dfrac{100}{1+x}$. Calculate work_piston, the work done as it strokes from $x = 1$ to $x = 5$ m using symbolic integration.

Part C — Numerical Approach
For the more complex oscillating force $F_{\text{ext}}(x) = e^x\cos(x^2)$, calculate work_ext, the work done from $x = 0$ to $x = 2$, using numerical integration (integral()).

Part D — Convert to Numeric Values
Convert all three results to standard double precision numbers: W_spring_num, W_piston_num, W_ext_num.

Staged Hints

Hint 1: Concept Hint (Work from Non-Constant Force)

When force varies with position $F(x)$, total work is the definite integral $W = \int_{x_1}^{x_2} F(x)\,dx$. For the spring, $\int kx\,dx = \frac{1}{2}kx^2$. For the piston, $\int \frac{100}{1+x}dx = 100\ln(1+x)$. For $e^x\cos(x^2)$, no elementary antiderivative exists, so numerical quadrature is required.

Hint 2: MATLAB Syntax Hint

Use syms x with int(F, x, a, b) for Parts A and B. For Part C, define F_ext = @(x) exp(x) .* cos(x.^2); and call integral(F_ext, 0, 2).

Hint 3: Code Skeleton 
syms x

% Part A
k = 500;
F_spring = k * x;
work_spring = int(F_spring, x, 0, 0.2);

% Part B
F_piston = 100 / (1 + x);
work_piston = int(F_piston, x, 1, 5);

% Part C
F_ext = @(x) exp(x) .* cos(x.^2);
work_ext = integral(F_ext, 0, 2);

% Part D
W_spring_num = double(work_spring);
W_piston_num = double(work_piston);
W_ext_num = double(work_ext);

Self-Check & Expected Properties

  • W_spring_num must equal exactly 10.0 Joules.
  • W_piston_num is $100\ln(6/2) = 100\ln(3) \approx 109.86$ Joules.
  • W_ext_num should be approximately $2.114$ Joules.

Engineering Reflection

Why is spring potential energy quadratic with compression ($U = \frac{1}{2}kx^2$) while gravitational potential energy is linear with height ($U = mgh$)? (Answer: Spring force increases proportionally with displacement ($F = kx$), so integrating yields $\frac{1}{2}kx^2$; gravity near Earth is constant ($F = mg$), so integrating yields $mgh$.)
